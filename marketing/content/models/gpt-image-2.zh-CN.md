## 新在哪

- **生成和改图是同一个模型**：OpenAI 官方把它定位成"用于快速、高质量图像生成与改图的新一代模型"，局部重绘（inpainting）直接内置，不用切换到别的模型。
- **改图一次最多带 16 张参考图**：不管是照着参考图生成新图，还是改一张已有的图，一次调用最多能传 16 张输入图。
- **分辨率上到 4K，还能出透明底**：1K / 2K / 4K 三档分辨率，1K 档下可以直接出透明背景（PNG/WebP），省了一步抠图。
- **画幅覆盖很全**：从 1:1 方图到 21:9 / 9:21 这种超宽超高的条幅，一共 16 种比例可选。

## 适合做什么

- 做电商产品图、图标、贴纸这类需要透明背景的素材，生成时直接带透明底，不用另外抠图。
- 改已有的图但要保真：比如只换产品图里的文案，其余构图、光线、包装细节都不动。
- 出对分辨率要求高的图（海报、大屏物料），用 4K 档位。

## 提示词要点

- **先说清楚用途和构图**：官方建议先点明"这是产品照 / 广告 / 示意图"这类用途，再说构图、画幅比例、关键元素放哪。
- **格式挑自己改得动的**：不用死记某种固定语法，挑你自己最容易读、最容易改的写法就行——大白话一段话、分点列，还是打标签都可以。
- **要写实就直接说"写实"**：想要照片质感，明说"photorealistic"或"real photograph"，并描述取景、材质、光线。
- **改图时把"改哪里"和"要保持的"分开写**：官方建议的格式是"只改 X"，然后单独列出要保持不变的东西——身份、结构、布局、光线、文字标签。
- **多轮改图一步步来**：把上一次生成的图当这一次的输入，一次只提一个修改要求，并重复一遍要保持不变的细节。
- **画面里要出现的文字用引号圈起来**：把要出现的文字放进引号，说明它的位置和字体感觉；生僻词或品牌名可以逐字母拼给它。

```text
一张深色巧克力蛋白棒的产品照片，1:1，透明背景（PNG）。写实摄影质感，柔和顶光，包装纸略微反光，
表面能看到坚果颗粒。包装正面印着文字"PURE FUEL"，粗黑体，居中偏上。背景干净，只保留产品和淡淡的
投影，不要多余装饰。只改包装文字，其余构图、光线、材质保持不变。
```

## 已知限制

- **透明背景只有 1K 档能用**：background 设成 transparent 或 opaque 时，分辨率必须是 1K，2K / 4K 不支持透明背景。
- **部分比例上不了高分辨率**：画幅是 1:1 时出不了 4K；不指定比例（auto）只能出 1K；5:4 / 4:5 / 3:1 / 1:3 / 9:21 上不了 2K，3:1 / 1:3 / 9:21 也上不了 4K。
