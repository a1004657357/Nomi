## 新在哪

- **20B 参数的开源图像基座模型**：2025 年 8 月首发即以复杂文字渲染惊艳，尤其是中文文字渲染的准确度。
- **持续出"日期版"更新**：不是发布完就不管了，2512（2025 年 12 月）版本明显改善了人像真实感和材质细节，减少"一眼 AI 感"。
- **配套 Edit 系列同步进化**：Qwen-Image-Edit 从最初版本一路更新到 Edit-2511，多图输入、人物一致性都在变强。
- **Apache 2.0 完全开源**：权重和代码都能直接下载，支持免费商用、微调、本地部署——Nomi 通过魔搭社区接入的正是这条开源线（当前对应 2025-12-31 发布的 Qwen-Image-2512 权重）。

## 适合做什么

- 需要本地部署、免费商用的开源图像模型，不想依赖云端 API Key。
- 中文文字渲染要求高的海报、封面、UI 场景。
- 想基于开源底座自己微调、接 LoRA 的开发者和爱好者。

## 提示词要点

- **正向提示词后面加质量词**：官方推荐英文加"Ultra HD, 4K, cinematic composition"，中文加"超清，4K，电影级构图"。
- **负向提示词认真写**：官方给出的参考示例包含"低分辨率，低画质，肢体畸形，手指畸形，画面过饱和"这类具体描述，直接照着改比空着强。
- **改图任务善用提示词重写**：官方建议改图时用 Prompt Enhancement Tool 重写指令，能明显提升编辑稳定性。
- **想要图里出现指定文字，就把文字原文写进提示词**：这是它最擅长的能力之一，写清楚比留白效果好。

```text
一张现代简约风格的书店海报，主视觉是一摞打开的书和一杯咖啡，暖黄色调，
标题文字为"深夜书店 · 24 小时营业"，副标题"一杯咖啡，一本书，一个安静的夜晚"，
超清，4K，电影级构图。
负向提示词：低分辨率，低画质，文字模糊，扭曲，画面过饱和。
```

## 已知限制

- 和更新的 Qwen-Image 3.0 不是同一条产品线：3.0 目前没有公开权重信息，只能通过官方或接入商 API 使用；这条开源线（包括 Nomi 接入的 2512 版本)可以直接下载权重本地部署，两者是并行的两个产品，不是简单的新旧版本替代关系。
- 官方在 2025-08-19 承认过一次"performance misalignments"（效果偏差），需要更新到最新 diffusers 版本才能达到预期效果。
- 20B 参数对本地硬件要求不低，这也是官方持续推出加速方案（如社区的 LightX2V 蒸馏方案）的原因。
