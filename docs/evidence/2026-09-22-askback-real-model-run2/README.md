1. **A12（6 错 / 15 调用）**：`draft_shots` 连着 4 次写坏 JSON（全部断在 `"durationSec"` 后面），
   现在每次都被告知「这段 JSON 在这里坏了」，但**模型仍然重发**。说明「说清楚」不足以止住这一族——
   下一刀要么让它别写 JSON 字符串（工具面/采样层），要么在这一族上直接转提问。
2. **A11（6 错 / 19 调用）**：`look_at_media` 仍回 `capability_execution_failed` 裸码——
   phase4 的域侧还没有一处改用 `refuseToModel`（合同 residual_risks 里记着）。

   `look_at_media` 给的 assetId，却被告知不在库里——**这两条互相矛盾，是下一个根因**（本轮未查）。
