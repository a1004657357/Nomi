**多角色一致性**

- `Omni-Flash-Ext`：1 或 3 张参考图驱动

**多帧叙事**
- `dreamina-multiframe`：2–20 张关键帧串成连贯视频
- `agnes-video-2.5`：支持文生视频 + 首尾帧 + 参考生视频

## 🛠️ 关键模式选择
每个模型模式（`modeId`）决定它能吃什么参考：
- **文生视频**（t2v/text）：纯文字，不吃图
- **图生视频**（i2v/first/firstlast）：需要首帧/尾帧
- **全能参考**（omni/ref）：最多吃 9–30 张图 + 视频/音频参考，保持跨镜一致

画布上引用视觉锚时，**必须选能吃图的模式**。用户只点名 t2v 就按文字生成；需要一致性时要换模式或去掉视觉锚。
