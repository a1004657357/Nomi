## 5. 发现

### ① H2 + H3 推动了 H1 推不动的那一格（**信号，未证明**）

H1 之后「以问代做」3/11 → 1/11，但「该问时问了」一格没动——少掉的两句改成了「不问直接做」。
**H1 把模型推向了动手，没推向工具。** run9 之后：

- 「该问时问了」**3/11 → 5/11**，提问卡 **4/18 → 6/18**；
- 新问的三句里，**A7 与 A12 精确落在 H3 新加那条的两种情形上**
  （跨面二义 / 两个要求互相拉扯），A10 是从正文搬进了卡；
- 「模型自己认为该问」9/11 —— 与 run5 持平，也就是说**多出来的不是「想问的变多了」，
  是「想问的里面走对通道的变多了」**。这正是 H1 → H3 这一串想要的形状。

**不能据此收工的理由**：分母 11、单轮对单轮，+2 在二项噪声里；
同一轮 A8 反向退了一格；误问同时 1/7 → 2/7。
**要下结论，至少再跑一轮同样的 18 句。**

### ② H2（范围 ≠ 价格）**没有拿到直接证据**

H2 针对的是 A5「帮我把这些都生成了」这种范围二义。run9 里 A5 **仍然没有调 `ask_user`**：
它一路 `draft_shots` 建了两个草稿、`generate` 出了报价卡，走查拒绝之后它在正文里说
「两个草稿都已保存……您希望在哪些地方进行调整？」——判为「答完顺口一问」。

也就是说：**这一轮没有任何一句用例因为「范围」而调了 `ask_user`**。
H2 改的那半句话**在这 18 句上没有被触发过**，既没有正面证据也没有反面证据。
A10 那次提问（「你想导出什么内容？」）形式上接近范围二义，但它的两个选项是
「导出现有视频文件 / 时间线上重新剪辑」——那是**做法**之争，落在 H3 (4) 上而不是 H2。

**建议**：要验 H2 得有一句明确的「全部还是选中的」用例，现在的用例表里没有。

### ③ T-QA-29 验收成立（见第 3 节）

新支路第一份样本，20.6 分钟 → 27.4 秒，回合继续。

### ④ 误问 1/7 → 2/7，新增那笔是判据的边界情形（见第 1 节）

N4 问的东西画布上不存在，模型说清了不存在再问下一步。
**不是 H2/H3 的代价，但也不该被当成零成本。** 下一轮盯这一格。
