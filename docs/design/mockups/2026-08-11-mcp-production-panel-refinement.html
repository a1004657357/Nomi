范围与逐处修复

★ 归位（用户两刀）· 一功能一个家 §1.5.2 制作任务从助手面板搬进任务中心；Nomi 侧只留「看片台 + 兜底」

① 助手面板不再挂制作块——两套操作不再相邻，误点消失，助手回归「只和 Nomi 聊画布」。
② 任务中心本来就在列这个 run（现状只有一行「brand.promo / 等待确认方向」，点了却跳去助手面板操作 = 一半住这、一半住那）。现在它就地长成完整制作卡。
③ 任务中心顶栏常驻、任何视图都能开（创作/生成/预览都在）；助手面板只在生成区有——任务本来就该住全局可达的地方。

砍 · 重复建设 不在 Nomi 复刻方向候选/样片批准的主入口

CLI 里一个回车 10 秒完事，用户人就在那边。Nomi 侧只显示「Codex 那边等你选方向」指路 + 一个收在次级的「也可以在这里决定」兜底键（打开现有弹窗）。两处文案不再需要同步。

留 · CLI 给不了的 产物可看可播 + 点击直达

终端渲染不了图——样片/粗剪/成片的预览是 Nomi 唯一不可替代的价值，放在卡里最显眼处，点击跳到画布对应节点/预览页。

内容硬伤 · productionRunView.ts:159 四种门共用一套文案 → 按门类分

方向门/样片门都在说「请核对支出边界；批准前不会调用付费模型」——方向门根本不花钱。改成每类门自己的一句话（中英齐）。

设计系统违规 · ProductionStatusPanel.tsx:33 IconLoader2 + animate-spin → NomiLoadingMark

§3.9.1：全仓唯一加载动画是旋转 logo。这处是本轮 MCP 工作新引入的违规。

语义 + 媒体 主按钮不挂警告三角；视频改封面+播放键
