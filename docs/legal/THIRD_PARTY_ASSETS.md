# Third-Party Assets

The machine-readable source of truth is `docs/legal/third-party-assets.json`.

## Release rule

- Gate 8 local development may use audited assets while their status is visible.
- `pnpm run check:third-party` validates hashes, coverage, and policy records without pretending release approval.
- `pnpm run check:third-party:release`, `pnpm run dist`, and the release system-test profile fail if a bundled asset has `releasePolicy: "blocked"`.
- An `external-user-supplied` integration is never copied into Nomi release artifacts.
- A `remote-on-demand` asset is downloaded only after an explicit import action, must use an audited HTTPS URL and pinned archive hash, and is cached outside release artifacts.

## Current findings

### Nomi Scene3D mannequin

`src/assets/nomi-mannequin.glb` and `src/assets/nomi-mannequin-animations.glb` are generated by `scripts/generate-nomi-mannequin.py`.

The generator defines the low-poly geometry, armature, rigid skin weights, and walk/run keyframes without importing an external model or animation file. It retains `mixamorig` bone names only to preserve existing Scene3D pose data. The script and generated artifacts are first-party Apache-2.0 assets, so the former bundled-asset release blocker is removed.

### Seedance browser extension

Original repository:

- `https://github.com/zhaihao118/Seedance2-Chrome-Extensions`
- audited upstream revision: `a646f24fb1fb1f566f0160b09a5c2dbb20b5551c`
- upstream manifest: `1.3.0`
- local user-managed manifest: `1.4.0`

The upstream repository declares no license. Nomi only discovers a user-supplied external path and must not package the extension. Local changes are intentionally not overwritten by the older upstream tree.

### Kenney Furniture Kit

VIBING Director exposes the official [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit) as a searchable remote catalog. The pack contains 140 GLB models and is declared CC0 by its official asset page; Kenney's [support page](https://kenney.nl/support) also states that asset-page content may be used commercially without required attribution.

Nomi does not bundle the archive. The main process downloads the pinned official HTTPS URL on the first explicit import, enforces an 8 MB response limit, verifies SHA-256 `e67652d0932cee41683f74711c03d3e192a2af9979ef8e6b237711f5482d46b0`, extracts only the selected allowlisted GLB, and records pack/file provenance in the project.

Poly Haven remains a browser/manual-import source because its [Public API terms](https://github.com/Poly-Haven/Public-API/blob/master/ToS.md) limit free API use to non-commercial use. Quaternius and BlenderKit also remain manual sources until Nomi has a stable, separately audited machine-download contract. Manual imports default to `需确认` instead of inferring a license from the selected website label.
