# Provider Adapter Self-Heal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to carry this plan out step by step.

**Goal:** 让 Nomi 在用户一次选择某供应商的多个模型后，自动发现真实 API 文档、生成受限声明式适配器、逐模式真实验证、失败后自动修复，并且只把验证通过的能力发布到画布。

**Architecture:** 新增独立的 `electron/providerAdapter/` 域。AI 只能生成可校验、可版本化的 HTTP 映射数据，不能执行代码或修改 Nomi 源码；候选适配器在隔离验证链路中运行，通过后才原子提升为活动映射。失败候选不影响上一个可用版本。UI 复用现有添加模型弹窗、模型卡片、按钮、状态色和设计 token，不创造第二套模型管理界面。

**Tech Stack:** Electron IPC、React 18、Zustand、Vercel AI SDK 4、Zod、Vitest、Playwright、现有 Catalog/Runtime/Design 组件。

---

## 范围

- 一次选择并接入同一供应商的多个模型，不要求逐个填写接口。
- 从供应商域名自动发现同域官方文档，调用 Nomi 已配置的文本模型生成声明式候选适配器。
- 对文本、文生图、参考图编辑、文生视频、参考图视频等已声明模式做真实请求。
- 参考图测试必须走 Nomi 正式的本地素材读取、上传/内联与请求构造链路。
- 失败时把脱敏后的阶段、请求摘要和错误交给 AI 修复，候选重新校验并回归测试；有明确次数上限。
- 只发布已通过的模型能力，保留最后一个可用版本，持久化运行状态并支持应用重启后恢复。
- 在现有添加模型流程和模型店家卡片内展示“验证中 / 已验证 / 部分可用 / 失败”，关闭弹窗不终止后台验证。
- 用 AGNES 作为首个盲测供应商：必须走自动发现、自动编译、自动测试路径，生产实现不得引用已有 AGNES 手写适配代码。

## 不做

- 不让 AI 写入或热执行 JavaScript/TypeScript，不调用 `new Function`。
- 不让 AI 修改 Nomi 核心源码，也不自动提交、拉取或执行第三方代码。
- 不让失败模式进入画布，不用未经验证的通用映射冒充成功。
- 不重做现有模型店家、抽屉或设计语言，不新增全局 CSS。
- 不在持久化运行记录中保存明文 API Key 或完整第三方文档正文。

## 安全与回滚不变量

1. 候选映射只允许受限 HTTP 方法、同源路径、受控模板变量和声明式响应路径。
2. 文档内容始终视为不可信数据；编译提示明确忽略其中的指令，只抽取 API 事实。
3. 每个运行绑定连接指纹；供应商地址、鉴权或模型集合变化后，旧候选不能继续发布。
4. 发布以模式为粒度，原子替换；每个旧活动模式在对应新候选通过前持续可用。
5. 所有错误、请求摘要、模型输出和日志先脱敏，绝不落 API Key。
6. 任何修复达到重试上限后进入“部分可用”或“失败”，不无限循环、不静默降级。

## 设计系统验收

- 验证页面仍位于当前 `OnboardingWizard` 的 `DesignModal`，宽度、标题区、底部操作区和间距遵循现有弹窗。
- 复用 `DesignButton`、`DesignCheckbox`、`DesignSearchInput`、`FoldableModelCard` 与既有 token；不写 hex、任意字号/圆角或新增全局 CSS。
- 主按钮从“添加 N 个模型”变为“接入并验证 N 个”，仍使用现有主按钮层级。
- 进度只显示真实完成数 `已验证 x/y` 和当前模型，不展示伪百分比。
- 模型卡片沿用现有成功/待处理状态表现；部分可用明确列出未通过模式，用户不用理解适配器术语。
- 所有可见文案走 `zh-CN` / `en` i18n；浅色、深色均以真实应用截图人工对账。

## 完成定义

- 用户只需配置一次供应商并选择一批模型；Nomi 自己完成文档发现、适配、验证与有限自动修复。
- 参考图不是“参数存在”测试，而是真实本地素材进入请求、供应商生成成功、返回媒体可读取。
- 每个能力状态都有可追溯的真实验证证据；失败能力不会出现在画布里。
- 应用崩溃/重启、修复失败或新候选回归失败都不会破坏最后可用版本。
- AGNES 的证明来自 Nomi 自动路径，且架构测试证明该路径没有借用现有 AGNES 手写代码。
- UI 与当前模型店家和设计系统一致，通过 i18n/token/巨壳门与真实截图人工验收。
