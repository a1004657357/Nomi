## 用户摩擦与设计判断

用户的真实目标不是“完成一次验证”，而是把一个新模型最终变成可用模型。现有流程把文档发现、AI 编译和整批验证串成一条必经链；其中任何一步慢、缺文档或失败，用户就停在“验证中”，关闭设置后也找不回任务。接入成功后又只能启停或删除，无法在同一连接继续增加模型。

因此接入必须是可继续推进的状态机，而不是一次性向导：自动发现是用户主动发起的加速路径，已有连接继续添加是日常路径，手填模型 ID 是目录接口失败时的降级路径，直接调用脚本是用户已经知道请求形状时的快捷路径。每条路径都必须能返回、取消、恢复和重新进入，不把“找到文档”或“AI 猜对调用”当准入条件，也不让用户在保存连接后被迫等待自动适配。

界面层级不能用一个尺寸解决所有内容。`760 x 560` 的设置外壳已经适合文件、权限、通用设置以及模型首页和连接详情；单模型的能力、脚本和任务需要更宽的工作面。因此最终采用混合结构：连接管理留在设置右侧，点击具体模型，或从模型首页创建一个直达脚本草稿后，打开 `880 x 640` 的第三层模型弹窗。复杂度只跟着已有明确身份的模型或草稿出现，不改变其他设置页的阅读宽度。

## 范围

- 设置左侧分类和 `760 x 560` 外壳保持不变；模型首页、连接详情、新增连接/模型和全局后台任务在设置右侧切换。
- 点击具体模型，或从模型首页选择“我已有调用脚本”并创建禁用草稿后，打开独立 `880 x 640` 第三层弹窗；模型详情、能力契约、模式级/模型级调用脚本和该模型的验证任务只在此弹窗内切换。
- 关闭第三层弹窗回到原连接详情或模型首页并恢复焦点；存在未保存能力或脚本时必须先确认，不能静默丢失草稿。
- 已有连接可以继续拉取或手填模型，不要求再次输入已加密保存的 Key。
- 新连接支持无鉴权网关、模型列表失败后手填 ID、缺文档后继续、验证失败后保留可修改候选。
- 验证任务提供逐模型进度、总超时、取消、后台恢复、重启后的明确待处理状态；不自动重放可能付费的请求。
- “我已有调用脚本”直接创建带明确模型身份的禁用草稿，并进入单模型第三层脚本编辑，不抓文档、不拉模型、不调用 AI、不自动验证；保存可运行脚本后才启用。
- 模型能力由显式能力契约表达模式、输入素材槽和参数；transport `taskKind` 只描述调用通道，禁止反推“全能参考、首尾帧、多参考图”等界面能力。
- 调用脚本获得当前 `taskKind` 和 `modeId` 上下文；模型级脚本保留为兼容回退，模式级配置优先。
- 设置界面覆盖长模型名、空目录、慢任务、错误、亮/暗色和窄屏。

## 不动项

- 不增加任何供应商专用分支；真实平台资料只作为通用契约和测试夹具。
- 不声称 SDK、WebSocket、浏览器登录态或常驻本地进程能被普通 HTTP 调用脚本完全接管；这些进入自定义节点/本地工作流兜底。
- 不从请求 mapping 或媒体类型猜模型输入模式；没有显式契约时诚实显示“输入能力未知”。
- 不向 renderer 暴露已保存的明文 Key。
- 不在应用重启后自动发起可能产生费用的模型请求。
- 不改设置里的文件与保存、通用等非模型分类的信息架构。
- 不为了容纳模型脚本而放大整个设置弹窗；第三层弹窗只由已有明确模型身份的条目触发，包括首页直达脚本创建出的禁用草稿，不承载连接级或全局设置。

## 页面归属与返回规则

| 页面/动作 | 宿主 | 返回位置 |
|---|---|---|
| 文件与保存、AI 策略、自动化权限、通用、关于 | `760 x 560` 设置外壳右侧 | 关闭设置 |
| 模型首页、连接详情、添加连接/模型 | 设置外壳右侧 | 上一级模型页面 |
| 全局后台任务 | 设置外壳右侧 | 模型首页 |
| 具体模型详情、能力与输入模式、该模型调用脚本、首页直达脚本草稿、该模型任务 | `880 x 640` 第三层弹窗 | 先退到模型详情；关闭后回原连接详情或模型首页 |
| 未保存确认 | 第三层弹窗最内层确认 | 继续编辑或丢弃并回到第三层的原入口 |

键盘层级固定为：最内层确认 -> 第三层内部子页 -> 第三层模型弹窗 -> 设置弹窗。任一层处理 `Esc` 后都不得继续冒泡关闭外层。

## 回滚边界

- 设置右栏页面栈、第三层模型弹窗栈与焦点恢复、能力契约、脚本运行时、验证任务生命周期分别保持模块边界和独立测试。
- 新持久化字段必须向后兼容；旧模型级 `customCall` 在没有模式级脚本时继续工作。
- 任何完整门禁或真实旅途失败时不推送交付分支，不触碰 `main`。
- 独立用户数据目录运行验收，避免污染用户现有 Nomi 配置。

## 真实用户任务矩阵

1. 新 HTTP 平台有 `/models` 和文档：填写 URL/Key，选择多个模型，转后台，再回到同一任务并完成或得到逐模型结果。
2. `/models` 返回 401、404 或非标准结构：保留已填连接信息，手填模型 ID，继续进入验证或脚本。
3. 文档不存在、文档站限流或 AI 编译不可用：任务在时限内进入可操作结果，用户可保存未验证候选、修改或写脚本。
4. 已有连接新增模型：不重新输入 Key，拉取新目录或手填 ID；原模型与连接保持不变。
5. 用户已有请求示例/脚本：从模型首页创建带模型身份的禁用草稿，并在单模型第三层弹窗中直达脚本编辑；无隐性网络请求，试跑成功后保存并启用，关闭后回模型首页。
6. 从连接详情点击一个视频模型，进入第三层弹窗；该模型有文生、多参考、首尾帧和未来自定义模式时，界面按能力契约收集素材，运行时把正确 `modeId`/`taskKind` 交给对应脚本。
7. 四个并发或历史后台任务：模型首页可看全局状态；从具体模型进入时只看该模型任务；两处都能重新进入、取消，重启后不会重复付费调用。
8. 未保存脚本关闭：第一次关闭只出现确认，取消后草稿仍在；确认丢弃后回到原连接详情或模型首页，且焦点回到原模型行或“我已有调用脚本”入口。
9. 键盘与窄屏：Esc 按确认、模型子页、模型弹窗、设置逐层退出；390x844 无横向溢出或文字遮挡，第三层在窄屏自适应为全屏工作面。
