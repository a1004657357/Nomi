# 模型接入搬进设置 + ComfyUI 工作流整页

2026-08-12 用户拍板。来源：2026-08-11 微信群反馈 + issue #58 + 参考项目 hero8152/Infinite-Canvas。

## 为什么

**「模型接入」现在没有家。** 它只住在一张 320px 的右上角浮卡里；设置里那个叫「AI 与模型」的
tab 名不副实——它管的是**MCP 代跑护栏**（`trustedHosts: nomi/claude/codex/cursor`、
`allowedProviders`/`allowedModels`/`maxSpend`），不是「我的模型」。于是：

- 群里那位要改阶跃星辰的 api url，「翻了半天没找到修改的地方」——不是他没找到，那儿本来就没有。
- 「api 配置需要一个单独的删除按钮」——同因，设置里那份是只读的。
- ComfyUI 工作流配置挤在 320px 里，要对着 `#110 CLIPTextEncode` 猜哪个是提示词
  （2026-08-11 提示词归类那个 bug 的体验根源）。

**参考项目只能借思路、不能借代码。** hero8152/Infinite-Canvas 的 LICENSE 明写「禁止用于任何形式
的修改封装成商业产品」+「二次开发必须保持开源」，且是 Python + 原生 JS，无组件可复用。
它那张图也没用任何图库（自写 JS + SVG + level/column 分层），和 Nomi 画布同一手法 —— 自己重写。

## 范围

### A. 设置新增「模型」tab（本轮做）
- `SettingsTab` 加 `'models'`，排在 `file` 之后、`ai` 之前；内容直接渲染既有 `OnboardingDrawer`
  （**同一个组件**，不复制实现）。
- 「AI 与模型」改名「AI 策略」——它管的是代跑白名单/预算/上传边界，不是模型清单。
- 删掉 `AiModelsSection` 顶部那段只读「模型连接」列表：下面的策略勾选框已经逐个列了 provider
  且带状态，上面那段是纯重复，留着就是第二个「模型的家」（P1 加新必删旧）。

### B. ComfyUI 工作流整页（本轮做）
- 从「模型」tab 里那台 ComfyUI 进入，占满设置内容区（760×560 装不下节点图，故走独立全屏层）。
- 左栏：后端地址 / 工作流列表（带缺件状态）/ **画布节点预览（实时）**。
- 右侧：只读节点图——节点显示中文名 + class_type + #id，点节点指定角色（提示词/首帧/尾帧/成品），
  节点上带「N 已用」角标（这个节点有几个输入被暴露成画布字段）。
- 数据全部来自既有 IPC（`analyzeComfyWorkflow` / `reconcileComfyWorkflow` / `parameters`），
  **后端零改动**。

### C. 浮卡（本轮不动，见「不动项」）

## 不动项（动了要另立 plan）

- **浮卡不改成遮罩式**。`OnboardingFloatingPanel` 头注释记着拍板：420px 全屏抽屉 + dim 被用户
  投诉「大幅度遮挡」，才改成 320px 无遮罩浮卡、工作区可见可操作。设置对话框是 `bg-black/45`，
  把接入整个塞进设置=原路退回那条拍板。故：**设置是家，浮卡是画布上的加速器**，两边渲染同一个
  `OnboardingDrawer`，不存在第二份实现。
- **MCP 代跑护栏不动**：`默认模型策略` / `可信发起方` / `支出与风险边界` 原地保留，只改 tab 名。
- **五 tab IA 的拍板为什么不再成立**：拍板那会儿「模型」= 几个 API key，塞 AI tab 里够用；
  现在多实例 ComfyUI + 自定义工作流已长成需要整页的子系统。按 §1.5.3「先分组（代价 0）」，
  给它自己的 tab 比继续往 AI tab 里堆更省用户注意力。

## 回滚

A、B 各自独立 commit。A 回滚 = 去掉 tab 项 + 恢复 label/只读列表；B 回滚 = 去掉整页入口，
浮卡里的既有导入面板未被删除、仍可用（B 不删旧路径，只是给它一个更宽的家；旧路径的收敛
放到 B 落地并走查通过后的单独 commit）。
