# Dreamina Seedance 2.5 接入计划

> 📋 方案待拍板 · 状态由 docs-autosync 自动登记，作者请按实修改

## 依据

- 即梦官方 CLI `version.json` 当前版本为 `1.4.15`，发布说明明确新增 `--model_version=seedance2.5`。
- 本机升级后的官方 CLI 帮助确认 `text2video`、`image2video`、`frames2video`、`multimodal2video` 均支持 2.5。
- 2.5 输出为 480P/720P、4–30 秒；全能参考最多 30 图、10 视频、10 音频，支持纯音频输入。

## 实施

1. 保留现有 Seedance 2.0 模型和旧项目标识。
2. 新增独立的 `dreamina-seedance-2.5` 模型与档案，在模型下拉中明确可选。
3. 复用已经验证的 dreamina 本地进程传输和结果轮询，只替换模型枚举及 UI 能力边界。
4. 修正 2.0 各变体的清晰度边界，使其与当前官方 CLI 帮助一致。
5. 允许已安装环境重跑官方安装器升级 CLI，避免旧版本看到 2.5 选项却无法执行。
6. 生成档案线协议文件，补 catalog、mapping、模式和参数回归测试。

## 验收边界

- 本轮不提交真实付费生成，不消耗即梦积分。
- 以官方 CLI 帮助、类型检查、档案生成检查、测试和完整门禁为验收证据。
