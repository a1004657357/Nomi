# Nomi 官网成本叙事重设计

日期：2026-08-17
分支：`codex/marketing-cost-redesign`
阶段：样张已确认，正式官网实现

## 目标

把官网的第一记忆点从「导演工作流」改成「把 AI 视频的成本打下来」，并用产品事实说明 Nomi 如何降低生成、工具、试错、人力和迁移成本。

确认样张后，正式实现落在 `scripts/marketing/*` 的既有生成体系中，并同步生成中文 `/` 与英文 `/en/`；样张保留为设计依据。

## 用户与真实摩擦

主要用户是已经使用即梦、云端模型 API 或本地 ComfyUI 的个人创作者与小团队。他们不是缺一个新模型，而是同时承担：

- 为多个平台和工具重复付费；
- 在故事、分镜、生成与剪辑工具之间搬运素材；
- 因上下文和参考丢失而反复抽卡；
- 把大量时间花在重复配置、执行和整理上；
- 项目被平台格式与云端账户锁住。

官网的任务是先让用户理解「已有能力可以继续用」，再证明 Nomi 能把这些能力组织成一条可编辑、可交付的生产线。

## Design Thesis

- **Audience and job**：已有模型、会员或本地工作流的 AI 视频创作者，希望少花钱、少试错并更快完成一条可编辑成片。
- **First-glance message**：把 AI 视频的成本，打下来。
- **Primary action**：下载 Nomi。
- **Secondary action**：观看 60 秒真实工作流。
- **Content rhythm**：强主张 → 真实产品证据 → 成本拆解 → 工作方式 → AI 助手与开放生态 → 上手 → 社群/项目合作 → 下载收口。
- **Visual direction**：Typeless 式单一主张与留白，ChatCut 式首屏后立即出现真实产品；Nomi 保留纸张暖白、墨黑与珊瑚橙，用「被划掉的成本层」形成记忆点。产品截图是主视觉，不用抽象 AI 插画。
- **Anti-patterns**：不做功能卡片墙、不在同一页面重复中英文、不承诺零成本或最低价、不用虚构节省金额、不让微信、商务、GitHub 与下载在首屏抢主次。

核心取舍：先把个人创作者的下载转化讲清，再承接团队项目；不同时把官网做成开源产品页和外包服务页。

## 核心文案

### Hero

H1：`把 AI 视频的成本，打下来。`

说明：`模型、会员、API、ComfyUI，都用你自己的。Nomi 把脚本、分镜、生成、剪辑和 AI 助手放进一个开源工作台，不再为平台套餐、重复工具和低效试错多付一遍。`

诚实限定：`Nomi 不承诺生成不要钱；它减少的是平台溢价、重复订阅、无效生成和重复劳动。`

### 成本证明

| 成本 | 用户摩擦 | Nomi 的机制 | 证据载体 |
|---|---|---|---|
| 生成成本 | 已有会员/API 仍被迫换平台充值 | 接即梦、任意 API、本地 ComfyUI，按任务切换 | 模型接入与画布截图 |
| 工具成本 | 文本、分镜、生成、剪辑分别订阅 | 一个开源桌面工作台贯通流程 | 真实工作流视频 |
| 试错成本 | 参考丢失、角色漂移、重复抽卡 | 视觉锚点和上下文持续连接 | 画布与时间线截图 |
| 人力成本 | 手工拆镜、搬素材、整理结果 | MCP + Skills 让 AI 助手执行重复工作 | AI 助手接入截图 |
| 迁移成本 | 素材、密钥和项目被平台锁住 | 本地优先、开放格式、源码可改 | GitHub 与本地存储说明 |

## 信息架构

1. **首屏**：Slogan、说明、下载、观看演示、真实 Nomi 产品画面。
2. **成本拆解**：四个可切换的成本维度；每个维度只讲一个摩擦、一个机制、一个结果。
3. **已有能力直接复用**：即梦 / API / ComfyUI → Nomi → 画布 / 时间线；Codex / Claude Code / Cursor 通过 MCP 操作 Nomi。
4. **一条片的完整路径**：故事 → 分镜 → 参考 → 生成 → 剪辑 → MP4。
5. **AI 助手真正开工**：不是聊天演示，而是建立项目、连接参考、调用模型、推进可编辑初稿；预算与导出由用户确认。
6. **三步开始**：下载、接入已有能力、完成第一条片；链接快速上手和完整手册。
7. **开放与合作**：开源版、团队定制/集成/贴牌两条路径分开呈现。
8. **社群**：加入用户群优先，作者微信和 GitHub Discussions 为补充。
9. **收尾**：重复核心承诺和下载 CTA。

## SEO Contract

- **页面意图**：寻找低成本、可自带模型、开源或本地 AI 视频工作流的用户。
- **URL**：中文 `/`，英文 `/en/`；保留现有 canonical 与互相 hreflang。
- **Title 方向**：`Nomi — 把 AI 视频的成本打下来`。
- **Description 方向**：明确开源、本地优先、自带模型/API/ComfyUI、MCP 与从分镜到剪辑的完整工作流。
- **H1**：唯一 H1 为核心 Slogan。
- **Heading outline**：贵在哪里 → 怎么降 → 如何完成一条片 → AI 助手如何开工 → 如何开始 → 社群与合作。
- **结构化数据**：继续使用与可见内容一致的 `SoftwareApplication`，版本和下载 URL 从现有构建真相源生成。
- **内部链接**：快速上手、用户手册、MCP 指南、GitHub、Releases、Discussions、商务咨询。
- **风险**：首屏视频必须有 poster、固定尺寸和低带宽降级，不能让媒体阻塞可读文本与 CTA。

## Locale Contract

- 支持 `zh-CN` 与 `en`，保持独立 URL，不在同一页面并排显示双语。
- 中文为本轮样张内容；正式实现同步更新 `scripts/marketing/content.mjs` 并由 parity 检查约束英文。
- 英文 H1 暂定：`Bring the cost of AI video down.`，实现前做自然表达校对。
- 高膨胀风险：导航、成本维度名称、下载按钮、团队合作说明。
- 所有按钮允许换行但不截断；移动端主 CTA 宽度稳定，语言切换保留当前页面上下文。

## Interaction Contract

| 交互 | Idle | Hover/Focus | Activated | Mobile | Reduced motion |
|---|---|---|---|---|---|
| 成本维度切换 | 首项激活 | 1px 描边与清晰焦点 | 更新机制、结果和证据图 | 横向可滚动或两列，不截断 | 无位移动画，直接切换 |
| 工作流步骤 | 首步高亮 | 显示可点击状态 | 更新截图说明 | 单列顺序浏览 | 取消视差与自动推进 |
| 视频播放 | poster 可读 | 播放按钮反馈 | 打开带字幕的 dialog | 全宽、可关闭 | 不自动播放 |
| 社群二维码 | 用户群卡片内常驻显示 | 无需点击 | 收尾 CTA 锚点滚动到二维码 | 二维码不超出视口 | 直接显示；锚点滚动关闭平滑动画 |
| 导航 | 正常文档流 | 下划线/焦点 | 锚点滚动 | 折叠菜单 | 关闭平滑滚动 |

动画只保留一个页面进入节奏、一个内容切换节奏和按钮反馈；全部使用 `transform` / `opacity`，不阻塞输入。

## System Contract

- 正式站继续复用现有 `--paper`、`--ink`、`--rule`、`--coral` 语义，并补充少量成本状态语义；样张先验证，不在本阶段改全局 token。
- 圆角不超过 8px；按钮最小高度 44px；不用 pill 堆叠。
- 图片使用现有 Nomi 真实截图和视频 poster；不新增装饰性 SVG 或渐变背景。
- 正式实现继续由 `scripts/marketing/*` 生成中英文静态 HTML，不创建第二套手写正式页面。
- 正式实现时删除被替换的旧 section 和 CSS，避免并行版。

## 实现范围

- 保留 `docs/design/mockups/2026-08-17-nomi-cost-homepage.html` 作为已确认设计依据。
- 更新 `scripts/marketing/content.mjs`、`template.mjs`、`styles.mjs` 与 `client.mjs`，由现有构建脚本生成正式双语页面。
- 使用 2026-08-17 从 `origin/main` 最新构建实拍的创作、生成、预览、3D 导演台与自动化设置截图；视频和 Logo 复用正式仓资产。
- 用户群二维码替换为 2026-08-17 提供的新群码，并在用户群卡片内常驻展示；收尾 CTA 直接定位到群码。
- 浏览器首次访问 `/` 时按 `navigator.languages` 顺序选择首个受支持的中文或英文；显式语言选择写入本地偏好并优先于浏览器判断。
- 语言判断脚本位于 `<head>` 且早于样式和正文：中文浏览器直接显示中文，英文浏览器在首屏绘制前进入 `/en/`，无需点击语言控件。
- 下载按钮根据 Windows、Apple Silicon 或 Intel Mac 直接请求对应安装包；无法可靠判断 Mac 架构时只在当前页展示安装包选择，不跳转 Releases 列表。
- 可点击验证成本切换、工作流切换、视频弹窗、作者微信弹窗、群码锚点和移动导航。
- 同步更新静态契约、Playwright 视觉测试、社交分享图和生成后的正式 HTML。

## 不做项

- 不更改 Release 资产命名、打包流程和下载统计。
- 不自动发布、不提交商务表单。
- 不虚构价格、节省比例、用户数量或客户评价。

## 验收

- 3 秒内能复述「Nomi 帮我降低 AI 视频生产成本」。
- 首屏只有一个主 CTA，桌面和移动端都能看到真实产品证据或下一段提示。
- 成本主张均有机制与产品证据，不出现零成本、最低价等无法证明的绝对承诺。
- 中文与英文均无截断、横向滚动或导航冲突。
- 键盘可完成导航、切换、打开和关闭弹窗。
- `prefers-reduced-motion` 下无自动播放和非必要位移。
- 样张在桌面与移动端完成截图和人工视觉检查后再交用户拍板。
