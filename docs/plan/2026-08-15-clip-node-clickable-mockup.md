# 剪辑节点连续预览与导出实现计划

日期：2026-08-15

## 目标

在最新 `origin/main` 上升级画布剪辑节点，保持现有时间轴为唯一编辑能力来源，只增加两项产品能力：

1. 节点默认只显示紧凑剪辑轴；点击片段后在轴上方展开一块连续的成片监视器，使用整条序列的全局播放头并跨切点连续播放。
2. 导出明确拆成「完整视频 / 独立片段」与「到画布 / 下载」四条路径；独立片段到画布生成 N 个视频节点并通过现有画布边表达来源。

## 架构约束

- 不新增节点专用的分割、复制、删除按钮或快捷键表。
- 抽出并复用主时间轴的快捷键命令分派和真实墙钟播放推进；主时间轴行为不变。
- `ClipNodeTimeline` 只保留单轨、低密度的显示差异；编辑继续通过 `timelineEdit` 的移动、裁切、分割、复制和微调纯函数写回 `meta.clip`。
- 预览只消费 `TimelineState + playheadFrame`，不以 selected clip 作为播放范围；选择只决定编辑对象。
- 导出继续调用现有 `exportTimelineToMp4`、canvas store `addNode/updateNode/connectNodes`，不新增编码或连线系统。
- 输出边不设置额外展示模式：沿用 `CanvasEdgeLayer` 的浅色默认线、默认无标签、点击命中区后显示现有 active-edge 控件。

## Interaction Contract

- `compact`：未点击片段时只显示标题、片段数、总时长和单轨剪辑轴。
- `editing`：点击片段后展开整条序列的成片监视器；点击位置同时定位全局播放头。
- `playback`：播放跨越切点时切换当前媒体但不重置总时间；拖动整片进度条可 scrub 任意位置。
- `timeline-editing`：拖动片段、拖入出点、点击标尺和现有快捷键共用主时间轴命令语义；预览区不承载编辑命令。
- `keyboard`：方向键逐帧、`S` 在播放头分割、`Cmd/Ctrl+D` 复制、`Delete/Backspace` 删除、`Shift+< / >` 微调、`Cmd/Ctrl+Z` 撤销、`Shift+Cmd/Ctrl+Z` 重做。
- `exporting`：四个导出动作分别进入 loading/success/error；相同动作执行中禁用，失败不创建半成品节点。
- `edge`：输出边默认浅色无标签；点击线条命中区后才显示既有关系控件，可按现有方式关闭或断开。
- `narrow`：浮动监视器按视口夹紧，不遮挡节点时间轴；导出菜单可完整操作。
- `reduced-motion`：播放仍按帧更新，不增加装饰动画。

## 验收门

- 默认无预览；点击片段才出现一块成片监视器，预览内不存在分割、复制或删除命令。
- 点击片段内部任意位置后播放头落在对应全局帧；播放跨越至少一个切点，当前媒体变化且总时间连续增加。
- 主时间轴与剪辑节点的快捷键映射由同一模块测试；节点编辑不触发背后的全局时间轴。
- 拖动排序、入出点裁切、分割、复制、删除、微调和撤销可在剪辑节点完成。
- 四个导出动作互不夹带副作用；完整到画布生成 1 个节点，分段到画布生成 N 个节点并各有 1 条来源边。
- 输出边默认无标签；点击边后才出现现有关系控件。
- 真实生产构建的桌面与窄屏截图无遮挡、裁切、横向越界或不可达控件。
- `check:filesize`、`check:tokens`、`check:i18n`、`lint:ci`、`typecheck`、`test`、`build` 全部通过。

## 回滚

回滚本功能提交即可恢复原剪辑节点；不改 `TimelineState` 持久化 schema，不需要项目数据迁移。

- 导出复用 `exportTimelineToMp4`，画布输出复用 `addNode/updateNode/connectNodes`；所有导出完成后才创建输出节点。
- 主时间轴与剪辑节点共用快捷键分派和播放时钟，节点预览未新增分割、复制或删除按钮。
