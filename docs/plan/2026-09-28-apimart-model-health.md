# APIMart 全模型体检（最小必要矩阵）

> 状态：✅ M1 已完成（2026-09-28；零生成调用）。L0/L1/L2 已落地，L3 付费矩阵留给 M2。

## 1. 为什么要做

0.22.3–0.22.4 的两个线上问题都是用户换着模型出图才撞出来的：APIMart 部分模型把结果地址给成字符串而不是数组（结果拉不回本地）、建连阶段被重置（连不上服务商）。我们接了几十个 APIMart 模型 × 多种模式，平时只有少数几条被真跑过，**形状漂移和上游下架都要等用户撞到才知道**。

## 2. 范围

只做 APIMart 内置渠道的全部生成模型（图片 / 视频 / 音频）× 模式；文本模型只做存活。其它供应商不做（用户：维护那么多供应商太麻烦）。

## 3. 四层，从零花费到最小花费

| 层 | 做什么 | 花不花钱 | 什么时候跑 | 抓什么 |
|---|---|---|---|---|
| L0 清单即代码 | 从 catalog 代码导出「模型 × 模式」清单与每条的**契约指纹**（创建 / 查询 / 状态映射 / 参数 / 参考通道的哈希）；清单本身就是体检名单，不另维护一份 | 不花 | 每次 CI | 名单漂移、契约写错 |
| L1 上游存活 | ①文档页还在不在（复用模型雷达的文档车道，给每个模型记下它的文档页）；②对被 ①标红的模型，发一个**缺必填字段、上游在扣费前就会拒掉**的请求，看回的是「参数不对」还是「模型不存在」 | 不花 | 每天 + 发版前 | 上游下架 / 改名（「Model not exist」）；同时是「删老模型」清单的输入 |
| L2 真实形状回放 | 录下每个模型 × 模式真实的创建 / 查询 / 结果响应（结果地址脱敏），单测用我们的解析器逐条回放：任务号、状态、结果地址 | 不花（回放）；录音来自 L3 或历史任务号的免费重查 | 每次 CI | 字符串 / 数组这类形状漂移（这次的主因） |
| L3 最小真生成 | 每个模型 × 模式真跑一次：最便宜档（最小分辨率、最短时长、1 张），走**真实 App 路径**（提交 → 轮询 → 落地到本地），参考类模式带一张真图 | 花，最少 | 发版前全量；平时只跑契约指纹变了的那几条 | 鉴权、参数被拒、轮询、下载落地的端到端链路 |

注意（L1）：`GET /v1/models` 里图片 / 视频模型的 id 和生成接口上的真实 id **命名不一致**（例：目录写 `seedream-5-0-pro`，生成接口是 `doubao-seedream-5-0-pro`，见 `scripts/model-radar.ts:211`），按名字比会天天误报，所以生成模型的存活不拿它判。「缺必填字段」的探测请求**先在一个模型上实测确认不扣费**，再推广到全部；任何可能被上游接受的请求一律不发。

## 4. 收据与发版闸

- L3 每跑通一条落一张收据：`模型 × 模式 × 契约指纹 × 时间 × 供应商任务号`（不含价格与花费）。
- 发版闸：清单里每一条都要有「当前契约指纹」的 L3 收据，缺的列出来；L1 报「上游不在了」→ 发版闸红，同时进「建议下架」清单。

## 5. 删老模型

只出**带证据的建议清单**（上游已下架 / 被同家新版本取代 / 很久没人用），**用户逐个勾选后才删**；删的时候，用过这个模型的旧项目节点要照常能打开（显示「模型已下架」，不报错）。

## 6. 实现拆分（交 Codex）

- **M1（medium）**：✅ L0 清单导出（catalog 层唯一 owner）+ 契约指纹；✅ L1 文档页关联（复用模型雷达，支持 `--offline`）；✅ L2 回放框架。录音目前只有 2 条真实的，且都是数组形状（Seedream 5.0 Pro、Nano Banana 2）；字符串形状没有真实录音，改为在测试里由真实录音派生（不另存夹具、不算录音）；其余 52 条待 L3。**变异校验的发现（09-28 协调会话）**：v0.22.4 给映射加的第二候选路径并不承重——解析器 `pathValues` 遇到「数字下标 + 非数组」本来就把字符串原样传下去（`electron/tasks/responseParsing.ts:32`），只去掉任一处测试都不红、两处都去掉才红。所以 0.22.3 用户「任务完成却一直停在『正在存到你电脑上』」的真因很可能不在查询解析这一层，还没确认（另开调查），M2 的 L3 真跑必须覆盖到「落地到本地」这一步。CLI：`pnpm run apimart:health -- --offline <样本目录>`。
- **M2（medium）**：L1 缺必填字段探测（先单模型实测不扣费）；L3 付费矩阵（复用 `tests/ux/_paidRun.mjs` 的付费闸与真实资料拷贝；点控件前先把节点移进可见区——0.22.4 RC 实测被 Agent 面板挡住的「生成」时灵时不灵）；收据文件与发版闸门岗。
- 两段都要变异校验：把 v0.22.4 的「字符串结果地址」兼容改回去，L2 必须红。

## 7. 不做

不测其它供应商；不做价格核对；不在 CI 里花钱（L3 只在本机 / 发版时由协调会话触发）。

- 仓库里已有：付费走查的闸门、真实资料拷贝与花费收据（`tests/ux/_paidRun.mjs:51`），L3 直接复用。
- 仓库里已有：APIMart 生成模型的接入都在 catalog（如 `electron/catalog/apimartImages.ts:134`），L0 从这里导出，不手写第二份清单。
