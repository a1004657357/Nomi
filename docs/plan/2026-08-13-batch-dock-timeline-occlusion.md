# 批量生成底栏遮挡时间轴修复（2026-08-13）

## 用户摩擦

生成画布无选区且存在待生成节点时，批量生成底栏固定在画布底部中央。时间轴默认折叠时，底栏与「展开生成时间轴」把手占用同一位置；底栏没有退出入口，导致时间轴入口被盖住，用户也无法收起这个底栏。

## 根因

- `CanvasBatchGenerateDock` 无条件使用 `bottom-4`，而 `GenerationWorkspace` 的时间轴把手同样锚在画布底部中央。
- 底栏展示条件只由待生成数量驱动，没有用户可控的临时隐藏状态。

## 方案

- 给底栏增加明确的隐藏按钮；隐藏只针对当前这批待生成节点，待生成集合变化或清空后自动恢复，不会永久吞掉批量入口。
- 时间轴折叠时把底栏上移，给时间轴把手留出点击空间；时间轴展开时保留画布内底部停靠。
- 用待生成节点集合 key 做纯函数展示判定，并补测试锁住“同一批可隐藏、批次变化自动重现”。

## 不动项

- 不改变批量生成、付费确认、并发偏好、依赖波次和任务中心逻辑。
- 不新增第二套批量入口，不修改时间轴本身的折叠状态持久化。

## 验收

- 单测证明当前批次隐藏后不显示，待生成集合变化后重新显示。
- Electron 批量生产走查证明：底栏不再盖住时间轴展开把手；点击隐藏后底栏消失，时间轴仍可展开。
- 完整门禁通过后合并现有 PR #64，不再创建新的 PR。
