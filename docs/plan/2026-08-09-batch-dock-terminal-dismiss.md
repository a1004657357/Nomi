# 批量生成底栏终态退出修复（2026-08-09）

## 用户摩擦

用户执行“生成全部”后，所有节点都已完成，但画布底部仍常驻“生成全部 0 个 / 并发 6”的禁用工具条。

根因是按钮计数使用真正的可执行节点集合 `eligibleIds`，而外壳展示条件只检查“画布有节点且当前无选区”。两个判断来源不一致，最后一个节点完成时只有计数变成 0，外壳不会退出。

## 范围

- 批量生成底栏只在当前分类仍有至少一个可执行节点时显示。
- 成功、运行中、排队中和不可恢复节点不为底栏续命；失败节点仍保留批量重试入口。
- 保持有选区时使用选区工具条、无选区时使用全分类底栏的现有分工。

## 不动项

- 不改变批量依赖排序、并发数、付费确认或任务中心状态。
- 不在完成后清空节点选择或删除批次历史。
- 不增加完成按钮、关闭按钮或第二套 dock。

## 结构保证

- 纯函数真值表锁住只读、选区和可执行计数三项展示条件。
- 现有可执行节点测试继续覆盖 idle/error 可跑、success/running/queued 不可跑。
- 定向测试、类型检查、lint 和完整 gates 通过。

## 验证结果

- 展示条件真值表与可执行节点范围测试通过。
- Electron 批量生产真走查通过：两个有依赖的节点完成后 dock 自动卸载，不再显示“生成全部 0 个”；失败节点重试仍可完成。
- 完整走查同时通过付费取消、依赖波次、并发持久化、通知原位更新和无 pageerror 检查。
- 完整 `pnpm run gates` 通过：453 个测试文件、4016 个测试通过，renderer 与 Electron 构建成功。
