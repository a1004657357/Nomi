# Nomi v0.21.0 发布计划

## 目标

把 `v0.20.1..01302f2a56d54d5bb3763b947181926713618a1d` 的完整主线能力发布为 `v0.21.0`，重点向用户说明：ComfyUI 多输入工作流、Wan 3.0、火山方舟 2026 模型、MiniMax H3、Gemini/Antigravity，以及多镜制作闭环。

## 范围

- 更新 `package.json` 版本到 `0.21.0`。
- 新增 `docs/release-notes/v0.21.0.md`。
- 在 `CHANGELOG.md` 顶部补充 `v0.21.0` 条目。
- 重建中英文官网、开发手册与新手指南中的发布版本元数据；让静态测试从 `package.json` 读取版本，移除每次发版都会过期的硬编码；在所有下载入口明确 macOS 12+ 最低版本。
- 从当前远端 `main` 建立独立 release 分支，通过 PR、RC、merge commit 和 `Desktop Release` 工作流晋级。

## 不在本次范围

- 不纳入尚未合并的 PR #179、#181、#194、#195。
- 不修改模型运行时代码或应用 UI；营销站仅同步版本元数据、下载兼容性说明和生成文件，不重做视觉与信息架构。
- 不把宣传片资产塞进 release PR；宣传片单独经过故事板确认、生成和视觉验收。
- 不宣称未完成的真实付费模型画质验收；区分契约/模拟链路与真实生成证据。

## 关键表述边界

- 通用能力只表述为：本地可判断的素材与参数错误会在请求发出前拦截，减少无效调用。
- CLI 身份、版本与能力证明仅属于 Antigravity 本地执行，不扩写成 APIMart 等 HTTP 渠道的共同行为。
- ComfyUI 多输入的验收使用模拟 HTTP/可解码媒体，不冒充用户私有 GPU 工作流实跑。
- macOS 未签名/未公证，Windows 未使用 Authenticode；非硬切转场是否已渲染需按当前导出代码复核后再写。

## 验收门

1. release worktree 基线干净且精确来自远端 `main`。
2. `pnpm run gates` 全绿。
3. release commit 普通 push 到 `codex/release-0.21.0-20260827`，创建 PR。
4. `Desktop Release Candidate` 对该分支与 `0.21.0` 成功，三平台产物与 manifest 齐全。
5. release PR 使用 merge commit 合入 `main`，不 squash。
6. `Desktop Release` 使用成功 RC run id 创建并公开 `v0.21.0`。
7. `releases/latest`、三个稳定安装包、更新 yml、官网中英文下载入口与应用更新入口全部做真实请求验收。

## 回滚

- RC 前：继续在 release 分支修复并重跑，不修改既有 RC 产物。
- merge 前：关闭或保留 release PR，不触碰 `main`。
- 正式发布工作流前：不创建 tag。
- tag/Release 创建后发现分发问题：不重写 tag；修复资产/官网路由，或按新补丁版本发布。
