# 官网一期：模型库 · 提示词库 · 技能库 · 功能介绍 · 新手教程

> 状态：🚧 进行中（样张已按 §12 拍板；阶段 B 的实现在 PR 里，C 验收与上线部署、D 上线后见 §10）。
> 范围拍板（用户 2026-09-28）：五块全做，中英双语，数据从仓库构建时生成；来源仓库许可证逐个核过（全部允许转载，按许可证署名）。

## 0. 一句话

仓库里已经有别人搜得到就会想要的东西——每个模型「能做什么」的档案、48 个带方法的技能、40 条效果提示词、6 个公开提示词合集——但官网只有 4 个能被搜索引擎收录的页面。这一期把它们按「一个搜索问题一个页面」生成成网页，每页先给答案，再带到 Nomi。

## 1. 为什么这么做（用户摩擦 + 结构约束）

**搜的人卡在哪（D1）**：

| 他在搜什么 | 他那一刻要什么 | 今天官网给他什么 |
|---|---|---|
| 「Seedance 2.5 能做什么 / 怎么写提示词」 | 这个模型的能力边界、参数、一段能照抄的写法 | 什么都没有（首页只提了模型名） |
| 「AI 视频 运镜 提示词」「产品爆炸图 视频 提示词」 | 一段能复制的写法 + 效果图 | 什么都没有 |
| 「AI 编剧 skill」「分镜 Claude skill」 | 一份能装进自己 Agent 的方法 | 什么都没有 |
| 「开源 AI 视频工作台 / 本地 AI 视频软件」 | 这软件到底能干哪些事 | 首页一屏介绍，没有完整功能页 |
| 「Nomi 怎么用」 | 从装好到出第一条片的路 | 快速上手 + 一份停在 0.16 的一页手册（还写着 Agnes 免费网关） |

**结构约束（D2）**：一个人维护，页面一旦要人手抄就一定会过期。所以只做**能从仓库数据自动生成**的页面；手写的只有模型介绍这一种（数据给不了的「新在哪、适合做什么」），而且要带出处和核对日期。

**已有的 SEO 结论必须守住**（`docs/seo/reports/2026-09-03-openseo-nomi-seo-strategy.md`）：不批量生成没有实质内容的页面；每页都要有证据；不加假 FAQ / 评分 schema；`llms.txt` 不做（`docs/seo/README.md` 已明确排除）。本方案用 §4 的「页面单位」规则落实这一条。

## 2. 先查别人（R5②）

2026-09-28 用无头浏览器打开 35 个同类页面，拿到 31 个（PromptHero、PromptBase 被防爬墙拦下，没有绕；Lexica 服务端报错；LobeHub 一个地址 404）。每页记了 1440 宽整页截图和标题、描述、canonical、hreflang、结构化数据、标题层级、内链。要点：

| 类型 | 看了谁 | 拿来用的 | 不学的 |
|---|---|---|---|
| 模型列表 | fal、Replicate、OpenRouter、Artificial Analysis | 按任务分组（文生视频/图生视频/改图）；每张卡「厂商/模型名 + 一句话 + 任务标签」；OpenRouter 的 `CollectionPage + ItemList + BreadcrumbList` 结构化数据最完整 | 价格与调用量（我们不写价格）；左侧十几个筛选器（我们只有几十个模型，分组就够） |
| 单个模型页 | fal Seedance 2.5、Replicate FLUX、Krea 视频功能页、即梦/Higgsfield 的 Seedance 2.5 提示词指南 | 标题直接写「能做什么/怎么写提示词」；页面给参数表 + 可照抄的写法；Higgsfield 那篇把「10 类场景 + 设置 + 为什么」写满，是排名靠前的原因 | 在线试跑区（我们是桌面软件） |
| 提示词库 | YouMind（把开源提示词仓库做成的网站，和我们的来源之一同一家）、Civitai、Runway 提示词指南 | 结果图挨着提示词；「复制」一步到位；按用途/风格/主体分类页；Runway 把运镜词汇（推、拉、摇、跟）做成一节 | 一条提示词一页、上万页（对我们是重复内容，见 §4） |
| 技能库 | skills.sh（Vercel）、LobeHub、Smithery、SkillsMP、Agensi | 一行安装/使用说明放在最显眼处；按分组浏览；标明「标准 SKILL.md 格式，能在哪些助手里用」 | 安装量排行（我们没有这个数据，不编） |
| 功能/教程 | Linear、Cursor、Krea、Runway Academy、Higgsfield、n8n | 功能页按「一块能力一段」讲，每段一张真实界面图；n8n 的「新手先做这几个」；Runway Academy 的「入门/进阶」分级 | 大段动画、装饰图（我们用真界面截图） |

**反方意见（为什么可能不该这么做）**：谷歌 2024 起专门打击「为了排名批量生产的页面」（scaled content abuse）。几百个模板页如果只是换个名字，会拖累整站。对策写进 §4：内容不够一页的合并成分类页；每个模型页必须有人写过、带出处的介绍才生成；公开合集不拆成一条一页。

## 4. 页面单位规则（防薄内容）

一个东西够不够单独一页，只看一条：**它能不能单独回答一个搜索问题，而且答案在页面上是完整的**。

- 模型：够（能力、参数、写法、限制）。但**只有写好了介绍的模型才上官网**（详情页和库首页的卡片都是）；没写的由每周同步列进「缺介绍」清单，写好再上。
- 技能：够（导演/编剧技能正文 5–20KB；广告与角色配方有完整配方、验收标准和效果图）。
- 效果提示词（运镜、构图等）：**不够**。一条只有一句话，拆成 40 页就是 40 个薄页。按分类合成一页，每条带锚点（`/prompts/camera#pan-scan-vista`），分类页本身就是一份「23 种运镜怎么写」的完整参考。
- 公开合集：**不拆**。这些提示词原文在 GitHub 上早已公开，一条一页是重复内容；一个合集一页，列出 Nomi 收录的那部分（标题 + 提示词 + 逐条出处），第三方示例图不转存、不外链视频。

## 5. 每类页面：任务卡、减法梯度、删除清单、卡点表（设计系统 §1.5.5）

这些都是新画的面，没有「现状」可对照，所以按新面三件产物来。

### 5.1 单个模型页

- **任务卡**：一个在搜「Seedance 2.5 能做什么」的创作者，读完知道这个模型适不适合他手上的活、提示词大概怎么写，就走（或者下载 Nomi 试）。
- **v1（推荐）**：一句话定位 → 能力表（能做哪几种生成、参考图/视频/音频上限、时长、分辨率、画幅）→ 新在哪（3 条）→ 适合做什么（3 条）→ 提示词要点（3–5 条 + 1 段示范）→ 已知限制 → 在 Nomi 里怎么用（1 段）→ 出处与核对日期。
- v2：v1 + 同家族其它版本对比表。v3：v2 + 用这个模型做的样片。样片要真跑生成，二期再说。
- **删除清单**：不放价格（中转价格一直在变，而且 Nomi 不经手钱）；不放「最强 / 第一」这类没出处的说法；不放基准分数，除非标注出处和日期。有人想比价，就去供应商官网看，页面给链接。
- **卡点表**：① 怎么知道有这个页：搜索、模型库列表、功能页「换模型」一节。② 动手前知不知道要付出什么：页面写明要自己接一家供应商的 Key，并列出 Nomi 里哪几家能用。③ 模型下线了看到什么：退役模型不生成页面，旧地址 301 到模型库。④ 凭什么信：能力表来自 Nomi 实际调用用的档案，介绍每条都有出处和核对日期。
- **这条路几步**：搜索 → 读 → 下载。不能再砍。

### 5.2 效果分类页（如运镜）

- **任务卡**：一个想让 AI 视频镜头「动起来」的人，找到一种运镜的写法，复制走。
- **v1（推荐）**：分类说明（一段）→ 条目网格（封面图、中英名、一句话提示词、复制按钮、锚点）→ 在 Nomi 里怎么用（节点上一键套用效果）→ 出处与许可证。
- v2：v1 + 每条示例视频（要生成 23 段视频，§12 单独问）。
- **删除清单**：不做一条一页（见 §4）；不做站内搜索框（一页最多 23 条，Ctrl+F 就够）。

### 5.3 单个技能页（配方类、方法类共用一个模板）

- **任务卡**：一个在找「AI 编剧方法 / 分镜 skill」的人，读到方法全文，知道怎么在 Nomi 或自己的 Agent 里用，就走。
- **v1（推荐）**：标题 + 一句话 + 分组/适用/许可证 → 怎么用（Nomi 里：Agent 自动用或在技能库里选；别的助手里：标准 SKILL.md，给 GitHub 文件夹链接）→ 正文全文（Markdown 渲染，自动目录）→ 配方类加效果图 → 出处与许可证全文（折叠）。
- **删除清单**：不编安装量、评分；不写「一键安装到某某助手」，除非真实验证过那条命令。只依赖 Nomi 工具的技能要说明「只能在 Nomi 里跑」。

### 5.4 三个库的首页

- **任务卡**：进来的人扫一眼知道有哪几类，点进自己要的那一类。
- **v1（推荐）**：标题带数量（「45 个 AI 视频和图片模型」）→ 分组锚点条 → 分组卡片网格。模型库分「视频 / 图片」两段，每段按分档排（旗舰 → 性价比 → 陪跑）。
- **删除清单**：不做筛选器和排序切换；不做「热门 / 最新」榜。

### 5.5 功能介绍

- **任务卡**：一个在比较 AI 视频工具的人，10 分钟内看懂 Nomi 能干完哪些活、跟在线工具差在哪，就走。
- **v1（推荐）**：一段话讲 Nomi 是什么 → 按创作顺序讲 8 块能力（Agent 对话出片、分镜表、生成画布与多版本、参考卡锁角色、3D 导演台、时间轴与导出、接任何模型、技能与提示词库）；每块一张真实界面图、三条具体能做的事、一个去深处的链接 → 本地优先与开源 → 下载。
- **删除清单**：不列路线图上还没做的能力；限制照实写（如「对口型暂不支持」）。

### 5.6 新手教程（`/quickstart` 扩写）

- **任务卡**：刚下载的人，按顺序做完出第一条片；卡住时找到对应的一条。
- **v1（推荐）**：现有四步（下载 → 接模型 → 跟 Agent 说 → 挑片导出）保持在最上面 → 「我想做 X → 走这条路」（角色每个镜头长一样、控制站位、运镜、加字幕、批量出片）→ 「卡住了看这里」→ 常见问题。
- **删除清单**：`/handbook` 这一页取消（内容并进来）；0.16 时期的「新」标记和 Agnes 免费网关说法删掉。

官网只**读**这些概念，不再养第二份。

| 技能/效果的种类、分组、标题、摘要、出处、许可证、封面 | `skills/*/SKILL.md` 前言（App 的技能加载器解析）+ `src/workbench/library/libraryGroups.ts` 的分组 | 提示词库、技能库的全部元数据 |
| 公开合集清单与离线种子 | `electron/promptLibrary/promptSources.ts` + `promptLibrarySeed.json` | 合集页 |
| 模型介绍（新在哪、适合做什么、提示词要点、限制、出处） | **新增** `marketing/content/models/<slug>.<lang>.md` | 只写档案给不了的文字，不重复能力数字 |
| 站点有哪些页面（sitemap、hreflang、导航） | **新增**：由页面生成器输出派生；删掉手写的 `scripts/marketing/site-manifest.mjs`（P1） | sitemap、SEO 监测 |

**导出方式**：新增 `scripts/site/export-site-data.ts`（tsx，直接 import 上表的 owner），写出 `marketing/data/site-data.json`（模型、技能、效果、合集，无价格）；页面生成器只读这个 JSON。App 那边的 PR 不带官网内容：每周一次的「官网数据同步」任务（仿 `seo-radar`）重新导出，数据变了就开一个只含官网文件的 PR，并列出「新模型缺介绍」的清单。

**图片**：技能封面和配方效果图每张 1–4MB，导出时用仓库已有的 ffmpeg（`@ffmpeg-installer/ffmpeg`）转成两种尺寸（卡片 640 宽、详情 1280 宽），提交在 `marketing/assets/library/`；检查时核对「源文件哈希 → 派生文件」清单，不比较字节。

**Markdown**：技能正文用 `marked` 渲染（加进 devDependencies；R5③：通用问题、不在护城河上、用现成的），原文里的 HTML 一律转义。

## 8. SEO 技术细节

- **标题与描述**：模型页「Seedance 2.5 能做什么、怎么写提示词｜Nomi 模型库」；库首页标题带数量；描述 50–160 字（今天英文首页和英文快速上手的描述超长，监测报了错，一并修）。
- **canonical + hreflang**：每页中英互指，x-default 指中文。
- **结构化数据**（只写页面上真有的东西）：库首页 `CollectionPage + ItemList + BreadcrumbList`；模型页 `WebPage + BreadcrumbList`；配方与效果 `CreativeWork`（作者、许可证、`isBasedOn` 指原仓库）；技能 `SoftwareSourceCode`（许可证、代码仓库）。不加 FAQ / 评分 / HowTo。
- **sitemap**：由生成器输出派生；`lastmod` 取「页面内容哈希变了的那天」，存在 `marketing/data/page-dates.json`，内容没变就不动日期。
- **内链**：面包屑；模型页 ↔ 适用于它的效果和配方（按图片/视频）；技能页 ↔ 同组技能；三个库都链回下载。
- **SEO 监测**：`docs/seo/config.json` 的页面清单改成读生成器输出，新页面自动纳入每周检查。
