⌘F 画布节点搜索（样张，待拍板，未实现）
按 ⌘F（Windows Ctrl+F）→ 画布顶部居中弹一个输入框。按节点标题 / 提示词 / 镜头号过滤当前分类的节点， 结果最多 8 条；画布上命中的卡片同步描边、没命中的变淡。↑↓ 选，回车 = 视口飞到那张卡并选中它、关掉搜索；Esc 关掉、画布恢复原样。 不搜别的分类、不搜素材库（那是资源库的搜索），不做模糊拼音（v1 只做包含匹配）。
