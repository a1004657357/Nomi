# Nomi v0.20.0 release plan

## Scope

- Release the complete `origin/main` history after `v0.19.0` as `v0.20.0`.
- Update the package version, changelog, release notes, and the R14 release audit.
- Include narrowly scoped release-branch fixes found during audit: catalog secret-boundary hardening, retryable safeStorage migration, category-bound canvas fitting, composer visibility, and release-pipeline integrity.
- Require exact target-architecture FFmpeg/FFprobe executables and packaged MCP startup on both macOS and Windows RC jobs.
- Keep multi-clip audio export compatible with the packaged FFmpeg 4.1.0 binaries while preserving unnormalized mix volume across the full timeline.
- Make every direct Electron test spawn use the shared Linux CI sandbox arguments instead of relying on host-specific `chrome-sandbox` permissions.
- Generate canvas performance assets with the repository's platform FFmpeg binary instead of assuming a system `ffmpeg` exists on the release runner.
- Resolve the packaged MCP launcher beside the Windows executable instead of treating `Nomi.exe` as the application directory.
- Run the clip editing, production MCP, and visible-media performance journeys in the immutable RC validation job.
- Build one immutable RC from the release commit, bind every artifact digest to its workflow run attempt and commit, then promote those exact artifacts through a verified draft GitHub Release.

## Out of scope

- No feature expansion beyond release-blocking findings or opportunistic refactors.
- No partial file selection from merged PRs.
- No direct push to `main`, mutable release assets, or rebuilt artifacts during stable promotion.

## Rollback

- Before stable promotion: close the release PR or rerun RC from a corrected release commit; do not reuse a failed RC.
- After stable promotion: preserve the immutable tag and publish a patch release for defects; do not replace published artifacts.

## Acceptance gates

1. R14 multi-role audit has no unresolved P0 findings.
2. `pnpm run gates`, `pnpm run test:e2e`, the CI-safe `pnpm run test:journeys`, and one explicit local J1-J5 suite pass on the exact release commit.
3. The release PR is merged to `main` with a merge commit after required checks pass.
4. `Desktop Release Candidate` succeeds for version `0.20.0` and produces macOS arm64/x64 plus Windows x64 artifacts and update metadata.
5. `Desktop Release` promotes the successful RC run to immutable tag `v0.20.0` without rebuilding.
6. The public Release uses the curated notes and exposes all versioned packages, updater metadata, five blockmaps, three stable installer aliases, and `SHA256SUMS.txt` with verified remote digests.
7. The bundled FFmpeg accepts the multi-source audio filtergraph, and the clip editing journey completes an MP4 export on the immutable RC commit.
8. Direct Electron MCP and memory test processes start on Linux CI without requiring a setuid `chrome-sandbox` helper.
9. The canvas performance benchmark can create all synthetic image/video fixtures on a clean release runner with no system FFmpeg installed.
10. The packaged MCP smoke resolves and starts the launcher from the Windows `resources/app.asar` beside `Nomi.exe`.
