# 控件名称与预览语义收口

## 目标

完整检查发现本轮翻译接线后，二十余个动作名称超出既有文案约束；两个媒体预览把装饰内容也算进同一个操作。修实际界面，不修改规则、忽略目录、数量或视觉基线。

## 实施范围

- 精简 `canvasComponents` 的中英文动作名称，保留全部插值、数量及实际含义；不改节点参数、生成模型、权限或回调。
- Director 的完整预览、品牌、简述、统计仍在原布局内；打开操作使用覆盖同一点击区域的独立原生按钮，仅包含原放大图标。展示文字不再充当操作名称，仍保留完整内容。
- 视频无封面时保留原播放操作及占位尺寸，移除被播放圆标覆盖的第二个装饰图标；单击、双击、键盘、视频比例和懒加载逻辑不变。
- 新测试执行真实组件的 SSR，核对可访问操作、内容和占位；现有视频交互及 Director 回归继续跑，最终做浏览器验证。

## 验收

1. 原图标一致性检查与控件检查无新增违规。
2. 中英文资源和插值集合一致；不改用户输入、持久化内容或提示词。
3. 真实组件回归、原交互回归、类型检查及浏览器截图检查通过；没有这些证据不宣称完成。
4. 不更新视觉截图基线，不提交新的真实生成请求。
