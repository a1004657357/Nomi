# 3d-director-desk 收编评估：逐维对比 + 路径决策（2026-08-03）

> 背景：群 2 用户推荐 [xiaozangao/3d-director-desk](https://github.com/xiaozangao/3d-director-desk)（「非常好用功能全面，现在用它导 mp4 再导入 Nomi」）。用户意向：**「把它整体过来，但还能弄成我们项目的一部分」**，要求先做详细逐项对比。

## 2. 三个关键洞察

1. **群友体感「功能全面」的实质**是三块我们真没有的：① 外部角色/动作导入体检链（任何 Mixamo/FBX 人形拖进来能用能动）② undo/多选/锁定/吸附这层编辑器基本功 ③ 掌镜记点+路线点显式编辑的手感。**模型库的富有一半是幻觉**：Mixamo Camille、37 个 GUO 绑骨人物、180 道具全是 gitignore 的本地素材包，仓库里没有；UE 人偶是 Sketchfab Standard 许可（再分发要审查）。真拿到手的是 18 个代码生成道具+程序素体。
2. **我们有他们整个没有的一层**：AI 驱动（自动摆位/运镜词表/参考路由）+ 角色实时操控录 take + 确定性离屏导出 + 姿势质量数学。他们的台是「手工预演工具」，我们的台是「长在生成画布里的 AI 导演台」。两者是互补拼图，不是同物竞争。
3. **同栈到 three 同版本**——搬运/移植的技术摩擦极低；但他们的骨架（3065 行 store/自己的 undo/自己的持久化/7765 行 CSS/无 i18n）与我们的门岗全面冲突。

## 3. 「整体过来」两种执行法

### 3A. 字面整体收编（vendor 转正为主编辑器，融合我们的 AI 层）
把他们的编辑器搬进仓库当 Nomi 的 3D 编辑器，删我们的（P1），再把我们的 AI/生成层焊到他们骨架上。
**代价**：create_staging_reference/cameraMoveBuilder 全部改写成生成他们的工程格式；possess+take 系统他们没有→反向移植我们的过去；离屏确定性导出管线重建（他们是 MediaRecorder）；i18n 全量提取（千条硬编码中文）；7765 行 CSS→token 归化；4 巨壳拆分；UE 素材许可审查；squash 史无考古、接手即唯一维护者。**≈ 把我们已验证的下半身锯下来缝到他们的上半身，数周纯工程且期间 3D 台冻结。**

### 3B. 部件级全面移植（以他们为 feature spec + 参考实现，功能面对齐，长在我们骨架上）+ vendor 对照台
不是「挑几个交互」——按 §1 清单**全面搬**，目标「功能面 ≥ 他们」；同时把整仓 vendor 进 `devlab`（dev-only 入口，不进用户 UI、不算并行版），移植手感时随时打开对照。批次（按群友痛点排序）：
- **P0-1 角色/动作导入体检链**（补最大洞：inspection 纯函数层+映射弹窗+自检轮播，他们这块相对自包含，MIT 可参考实现）
- **P0-2 编辑器基本功**：undo（commitMutation 单口模式值得抄）/多选/锁定/吸附
- **P1-3 掌镜 Enter 记点** + 逐点身体部位追踪 + 防抖（并进我们轨迹系统）
- **P1-4 路线点显式编辑**（到达时间/停留动作/弧长 timing/防穿模）
- **P2-5 手感细节**：灵敏度设置、viewport 视角手柄、双 FOV/监看对调
- **P2-6 18 镜头模板收编**（含贡献者署名机制，融进我们 13 招词表）
每批独立过五门落 main，3D 台不冻结，AI 层零重写。

### 判定建议：**3B**
第一性理由：他们做好的是「手工预演工具」这层（已商品化，libtv/tapnow/它都在做）；我们的结构位置是 AI 能驱动的导演台（抄不动的部分）。3A 买进商品化层、重写差异化层，战略倒挂；3B 把他们当免费的 spec+参考实现，两全。用户「整体过来」的诉求在 3B 里的落法=**能力清单整体过来 + 整仓 vendor 进 devlab 随时可跑对照**，而不是文件树转正。

## 4. 决议（2026-08-03 用户拍板）

**定案 = 3B 部件级全面移植**，用户原话意图：「把他的模型找过来，砍掉一些没有特别重要的，剩下的全部变成我们的这样」。优先级按用户点名重排：**①模型（库+对模型的操作） ②姿势/动作（用户判定我们现有姿势观感差，以他们为参照重校） ③鼠标操控（含缩放） ④运镜模板**。诚实边界已同步用户：对方模型库一半是 gitignore 本地素材包拿不到，可持续解=移植其「角色导入体检链」让任何 Mixamo/FBX 进得来。
