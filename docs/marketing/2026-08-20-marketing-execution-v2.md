## 1. 诊断：问题不是素材不够，是从没扣扳机 + 传播单元错了

| 指标 | 现状 | 读数 |
|---|---|---|
| 累计下载 | 3363（2026-08-16） | 近 21 天日均 **36**，区间 18–61，**曲线完全平坦、零尖峰** |
| GitHub | 423 star / 91 fork / 3 open issue / 2 watcher | fork 率 21%（常规约 10%）——来的是会动手改的开发者 |
| 平台 | Windows 71% / macArm 19% / macIntel 10% | 量主要来自中文 Windows 圈，不是英文开发者圈 |
| 版本 | v0.20.0（2026-08-17），1–3 周一版 | 新版下载主要是存量用户更新，不是拉新 |
| 素材 | 60s 中英片脚本、demo.mp4（无配音）、5 张真实截图、Show HN 稿、小红书稿 | **一条都没发出去** |

平坦曲线 = 现在的量是自然渗漏（搜索 + 口碑），营销贡献约等于零。做了 6 份营销文档，零次发布动作。

**两条根因：**
- **R1 从没扣扳机。** 稿子写完就停在仓库里。
- **R2 传播单元错了。** 我们发的是功能截图，竞品发的是**成片 + 可复刻的工作流**。

## 2. 竞品在怎么打（2026-08-20 查证）

**LibTV**（liblib.tv · LiblibAI 出品 · 2026-03 上线）
- 定位：「首个同时为**人类与 Agent** 设计的 AI 视频产品，无限画布 + 节点式工作流」。首页现挂 Seedance 2.5 / Minimax H3 / **导演台** / **skills** / 逐帧拉片。
- 传播主体是作品不是功能：《脚步》抖音 2 亿曝光 / 200 万赞；《牡丹记》北影节 AIGC 最佳影片，卖点写成"3 个人、2000 块"。
- 价格：Seedance ¥0.4/秒，对外称比同行低 76–92%。B 端首月签约 300 家短剧公司。

**TapNow**（tapnow.ai）
- 首屏原文：「**你的创意操作系统**——TapNow 是用 AI 智能体创作的最佳方式。统一调度文本、图像、音频与视频模型，零摩擦。」
- 首屏是企业 logo 墙：Alibaba / Google / TikTok / ByteDance / Tencent / WPP / HONDA / ANTA。
- 增长引擎：**TapTV 社区 1 万+ 可一键克隆的工作流**，每个爆款都附完整节点流程 → 新手克隆 → 改素材 → 再产爆款。订阅 ¥699–4999/月。

**三条结论：**
1. **它们的传播单元是「成品 + 可复刻工作流」。** 这是我们和它们最大的差距，且这个差距不是钱堆出来的，是选择。
2. **「画布 / 节点 / 多模型聚合 / Agent 驱动」的定位词已被资本占满。** 再在这条轴上讲功能是在别人主场打。
3. **它们靠别人的成功说话**（获奖、品牌、300 家公司），从不自吹功能。

**它们结构上不能做的一件事（这就是我们的空地）：**
公开「这条片真实花了多少钱」。积分差价是它们的利润，晒账单等于自曝加价率。
我们不靠推理差价活着，**账单可以摆出来**。这是主张不改的前提下，唯一能把"成本"从口号变成证据的做法。

> ⚠️ 表述红线：**不许写「不赚差价 / no middleman」**（apimart 通道带 `?aff=` 联盟参数，见 intro-copy-kit §6）。
> 正确写法是「你用自己的 key 直接付给模型方，**这条片花了多少，账单摆给你看**」——讲透明，不讲抽成。

## 3. 两条线

### 线 A · 中文周更：每周一支带账单的成片

**目的**：把官网那句"把成本打下来"变成每周一次的可验证证据，同时积累英文大发布要引用的真实案例。

**铁律（缺一不发）**：每支都必须同时带三样——
1. **成片**（15–30 秒，能独立成立，不是功能演示）
2. **真实账单**（`ProductionDetails` 的实际花费截图，精确到分）
3. **可复现的东西**（提示词全文 + 用了哪个模型 + 技能包 `.nomiskill.json`；项目分享包做完后换成一键导入的工程文件）

**文案母版**（三平台各自改写第一句，不许一稿群发）：
> 这条片 XX 分钟做完，花了 ¥X.X。用的是我自己的 key，账单在第二张图。提示词和工程都在评论区，你可以下下来改。

**节奏**：每周一支，周四发。小红书 + B站 + 即刻 + 微信群同日，公众号隔周合并一篇。

**为什么这个能打**：竞品能晒作品，晒不了账单；能晒工作流，但那是锁在它平台里的工作流。我们两样都能给，而且给得出去。

### 线 B · 英文大发布：攒够弹药再一次性打

**不许零敲碎打发。** HN 只有一次机会，沉底就废。

**发射条件（四条全绿才发，防无限拖延）：**
- [ ] 项目一键分享（`.nomi` 分享包）做完 —— 见 §4 P0
- [ ] 中文周更攒够 **4 支**成片（发布帖里要能引用真实作品，不是空谈）
- [ ] 60s 宣传片配音完成（脚本和素材已在 `2026-08-01-nomi-launch-film-scripts.md`，只缺音频）
- [ ] Windows SmartScreen / macOS 未公证 有一页明确说明页（英文用户对未签名安装包比中文用户敏感得多，这是最大的转化漏点）

**发射动作**：Show HN + Product Hunt + Reddit 三子版（r/comfyui / r/aivideo / r/LocalLLaMA），稿子全部已在 `intro-copy-kit.md` §2–§3，**直接用，不要重写**。
（已于 2026-08-20 修正：文案包里 "13 MCP tools" / "9 个 MCP 工具" 两处数字都过期，实测 `electron/capabilityCore/mcpToolCatalog.ts` 注册 **15 个**，已全文改齐。发之前仍要按 §6 红线逐条过一遍宣称。）

## 4. 前置基建（营销工程需求，按优先级）

这三件是营销的基础设施，不是产品功能。没有它们，上面两条线跑不动。

**P0 · 项目一键导出 / 导入（`.nomi` 分享包）**
现状：项目**不能**打包分享，只有技能能导出 `.nomiskill.json`（[SkillLibraryPanel.tsx:99](../../src/workbench/skillLibrary/SkillLibraryPanel.tsx:99)）；项目只是磁盘目录（[bridge.ts:369](../../src/desktop/bridge.ts:369)）。
为什么是 P0：TapNow 的 1 万个可克隆工作流就是靠这个滚起来的。没有"一个文件发给别人、别人一键复现整个画布"，线 A 的"可复现"只能给提示词文本，复刻回路断在最后一公里，线 B 也少一个杀手锏。

**P1 · 账单卡片（一张能截图能发的「这条片花了 ¥X.X」）**
现状：成本数据已经有了——生成前 [SpendConfirmDialog.tsx:9](../../src/workbench/generationCanvas/spend/SpendConfirmDialog.tsx:9) 预估，项目级 [ProductionDetails.tsx:56](../../src/workbench/production/ProductionDetails.tsx:56) 显示已授权/预留/实际/待结算。
缺的：这些数字散在面板里，不是一张能直接发出去的证据。需要一个"这条片：X 个镜头 / X 分钟 / ¥X.X / 用了哪些模型"的可导出卡片。这是线 A 每周的核心传播物。

**P2 · 60s 宣传片配音**
脚本（中英）与逐镜素材映射已完成，`demo.mp4` 47 秒无旁白无配乐。这是线 B 的发射条件之一。

- 打中文创作者最痛的点——一致性崩脸，也是我们最强的能力（锁一次，后续镜头继承）

## 6. 停止清单

- **停止**在价格数字上和平台比高低（LibTV ¥0.4/秒是资本补贴，比不过；我们比的是透明，不是低）
- **停止**做面面俱到的宣传片（60 秒讲 5 件事 = 一件都没记住）
- **停止**在没有作品的情况下发功能截图
- **停止**英文侧零敲碎打试水（HN 只有一次机会）
- 沿用 v1 里仍然成立的四条：不抹黑竞品、不刷榜、不写软文、不雇 KOL（钱花在帮真实创作者出片上）
