## 不能偷换的验证与许可边界

- “市场验证”这里仅指公开仓库采用信号 + 原作者公开产物，并非转化率/付费销售额验证，也不是 Nomi 模型实测。PicoTrex/YouMind 是聚合仓，保留原作者、原帖及仓库许可证；不能把仓主署名冒充原作者。
- LichAmnesia 的 LICENSE 明示 all prompts original works contributed，README 每项有本仓 images/*.png，前8来源最清晰。只能称原仓配图，不能假称Nomi生成的视频。
- jnMetaCode NOTICE §A 明列 templates/ 与 skills/shortfilm-prompt 为 MIT；§B 把 prompts/ 完整原文和跨文件引用句列为 Mx-Shell all rights reserved。旧 remediation 的单行“万能电影感”不能仅凭根MIT就照抄。showcase 明说自家成片 still pending，不能拿它当实测图证据。
- songguoxs 无许可证，拒收；jamez-bondos 根CC BY有目录ATTRIBUTION与OpenAI例外，未逐文件查清前不收；davila7 是开发类范围拒收，不计许可证拒收。
- 34条中明确许可证拒收2条（无许可、Mx-Shell）、许可例外未查清暂缓1条、范围拒收1条；前30是内容候选，其中Pico 11条许可声明冲突、JN atmosphere 1条来源冲突暂缓，25–30证据不足，不挤进首批15。
- 生成式扩图/高清修复可能重画纹理，不能标注为无损；六视图不等同真实3D几何。按钮文案不能许诺模型必然成功。

## 标准与官方样例

- https://agentskills.io/specification：name/description为必需；license可选；metadata是字符串到字符串映射；其余可选顶层字段如compatibility/allowed-tools。建议Nomi扩展放标准metadata的字符串键（例如 `metadata: {nomi.preview: "assets/preview.png", nomi.appliesTo: "image"}`）；不要新造skill.json，也不要把官方可选license误说为SKILL格式必需（它只是Nomi收录策略必需）。
- 官方完整样例与spec HTML已放 official.json（每项url+body），algorithmic-art 与 canvas-design 均未经截断。algorithmic-art 的 LICENSE.txt 为Apache-2.0；canvas-design许可证也已取进sources.json files。
- 注意官方metadata只能字符串值，嵌套 `nomi: {preview: ...}` 是Nomi偏差；用户示例nomi.preview可采用标准metadata扁平键实现。
