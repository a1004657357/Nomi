## 不能伪装为接入完成的项

1. `director-catalog-archive`：`extractVerifiedZipEntry` 手读 ZIP 中央目录、局部头，再用 zlib.inflateRawSync；`writeFileAtomic` 另写发布。替换采用**已有 fflate** 的有界提取与现有文件发布 owner。保留可信归档 SHA256、单条目名字/路径、加密/方法拒绝、声明尺寸和实际输出界限。先写损坏头、越界、错误尺寸、压缩炸弹/上限、重复/缺失条目及发布失败 parity，再替换。没有声称跑过 spike，当前函数的 maxOutputLength 保护不能丢。
2. `snapshot-structural-sharing`：`replaceEqualDeep` 确为通用算法。[TanStack 源码](https://github.com/TanStack/query/blob/main/packages/query-core/src/utils.ts) 是准确替代候选，但 query-core 不是当前直接依赖；react-virtual 不提供它。Immer producer/patch 和 SWR boolean compare 不是等价返回 API。需先决定受支持的 store/API 或单独批准依赖，并比较函数、non-plain、null-prototype、稀疏数组、键增删与未变子树 identity；本批不加包、不更换实现。
3. `renderer-external-stores`：`useModelBoxPreference` 与 `useCanvasPerformance` 仍有模块 listeners/notify。已有 Zustand vanilla 可接管机制；保留一次加载、写回/失败顺序、localStorage 和偏好字段，先做多订阅者、卸载、失败恢复与缓存加载 parity。涉及模型显示状态的生产改动留给对应 owner，不在本批动冻结面。
4. `desktop-string-interpolation`：locale 数据和插值机制分开。desktopT 的 String.replace 不是 i18next；在原同步 API 下先验证 i18next 的主进程 bundling/初始化、locale 选择、中文逐字、英文与未知占位符回退，再移除手写替换。当前并未替换。
5. `web-bridge-png-fixture`：`preset-tasks.cjs` 包含 PNG chunk/CRC 编码，**不是纯数据**。Node zlib.crc32 是可替代 CRC 循环的已有标准 API，但不等于完整 PNG encoder。优先把固定合成 fixture 的字节生产交还测试 owner，用已安装 Playwright 的公共截图 API作离线候选，保持 512x512、四种颜色、引用关系和 realSubmit:false；不把 Playwright 放入 Web 服务运行时。完整编码/部署替代仍需验证；本批没有生成、提交或读取真实媒体。

三项新增 under-review 的期限均为 **2026-11-15**：

- `vendor-submission-ledger`：间隔是 Nomi 策略，但跨进程预约/目录锁是手写通用机制。既有 workspace manifest lease 是真实参照，不是可不加证明地直接替换；其持有者存活、初始化、发布、恢复语义须与 settings 台账比较。内存 rate limiter 不能证明跨进程账号节奏。需真实多进程、活但慢 owner、崩溃恢复与 horizon 证据；本批未运行这些验证。
- `controlled-editor-echo-ledger`：Tiptap setContent 确有 emitUpdate，但没有替调用方建立 owner revision。当前字符串账本对“外部恰写回同值”和回声存在已知歧义。评估 revision/transaction identity 后再替换，保留快速输入、迟到旧拍、撤销、切节点与外部改写测试；不以本批登记声称歧义已修复。
