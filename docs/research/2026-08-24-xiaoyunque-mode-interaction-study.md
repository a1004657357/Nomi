## 模式清单与入口

短剧&漫剧 Agent（漫剧=画风非独立模式）、Agent 模式（通用对话创作）、沉浸式短片、图片创作、一镜到底、爆款复刻；画布为 Agent 模式/沉浸式的附属开关 + 独立自由画布入口；重制转绘在短剧 Agent 顶部标签行；3D 导演台是短剧画布内节点；智能预演是分集编辑器底部片段轴按钮；剧本助手内嵌短剧剧本阶段。**无口播模式。**

## 核心发现：三档模式强度并存

| 强度档 | 模式 | 交互形态 |
|---|---|---|
| **重管线** | 短剧 Agent、重制转绘 | 固定步骤流水线 + 显式确认闸门 + 分集状态机，对话几乎不参与 |
| **对话主驾** | Agent 模式、剧本助手 | 多轮对话唯一入口，画布可开可不开（多会话标签页并行） |
| **单发直出** | 沉浸式短片、图片、一镜到底、爆款复刻 | 一句话/表单直出，零中间态 |

三档并存不打架，靠每模式自己声明：几步、哪里停、产物粒度。

## 模式 × 交互差异表（摘要）

- **短剧 Agent**：固定 6 步（上传剧本→确认设定→全局角色→全局场景→分集/故事板→合成导出）；剧本概要「点击确认」；角色「提取不同时空妆造特征、精准映射对应集号」「后续角色自动参考已建形象」；故事板 @引用资产/增删镜头/首尾帧截取/垫图；分镜确认后生成；支持批量多集。
- **重制转绘**：环节一~十固定管线；**「确认顺序并解析」不可逆闸门 = 弹确认框 + 按时长积分预估 + 明示解析后不可改序/增删/换地区**；分集状态机（未解析→解析中→完成/失败标红），**「重新解析」一键重试所有失败集、不影响已成集**；资产库「定妆」（角色卡带原片参考对照）；分镜工作台三栏四视图（转绘/原片/白模/对比）。
- **Agent 模式 + 通用画布**：「左侧空白画布、右侧 Agent 对话」，产物自动落画布；**抽卡记录：同提示词结果折叠为一组、可指定生效版本**；@引用六种方式；节点工具（旋转裁剪抽帧/全景图/打光/镜头调节/涂鸦/反解析/33 种预设运镜/拼图）；「一键优化提示词」「会在需要的时候确认你的创作需求」。
- **智能预演**：治「首尾帧只能保两镜一致、多镜只能反复抽卡」——选一组片段（>2 个、引用素材 ≤9）→**先生成分镜图自动插回片段作引用（绿点提示）→确认无误再生成视频**；单张分镜不满意走「去画布编辑→生图→资产库拖回」逃生口。
- **3D 导演台**：画布内节点；五步法（定空间→定动作→定镜头→定节奏→回画布）；150+ 道具/动作库/运镜库/AI 识图转白模；产物回画布成图片/视频节点接入生成链路。
- **剧本助手**：三阶段合同「故事设定→分集大纲→剧本正文」各有明确产出；对话共创替代一次性生成；四维定位微调；历史记录查看/比较/回退。

## 共享 vs 独占

共享：积分、资产库+@机制（对话/画布/故事板通吃）、抽卡范式、输入框参数区、部分画布工具。独占：短剧侧（剧本解析/角色全局生命周期映射/故事板/智能预演/3D 导演台/重制转绘/白模）；通用侧（创意助手/多会话/涂鸦/反解析/拼图）。**注意：它有两套画布**（短剧资产画布 vs 通用创作画布），菜单快捷键几乎一致但节点集与有无对话不同——双维护双心智。

## 对 Nomi 的校准结论（已采纳）

1. **「模式=流程合同」做成三档强度**：合同第一字段=强度档（重管线/对话主驾/单发直出）；与 Nomi 的三姿态（纯对话/对话领路/舞台为主）正交——模式定流程结构度，姿态定谁领路。
2. **不可逆闸门三件套**：确认框 + 花费预估 + **明说过闸后冻结什么**——Nomi 确认卡补第三件。
3. **资产=唯一真相源、分镜只引用**：改一处全剧同步（画面+声音）；新角色自动参考已有——与 Nomi 锚/引用边同构，坚持引用制。
4. **每个中间产物有原位编辑的家，画布是兜底精修层，对话只是修改入口之一**——「纯对话」标准精确化为主链走得完，结构性编辑跳各自的家。
5. **它的坑：两套画布并行版**——Nomi 一套画布 + 模式档案声明可用节点/工具集（P1 正面教材反着看）。
6. **局部重试 + 抽卡折叠组**：失败=分级状态机局部重试；重生成=折叠成组指定生效版本——对标 Nomi 逐镜返工与 result history 的交互形态。
7. **智能预演 → Nomi P4.5 候选**：在锚与视频之间垫「分镜图先行」便宜一致性检查点；与 Video Agent 调研「草图/首帧候选→锁定→再生成」互证。
