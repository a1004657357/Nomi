# 产品侧 Agent 交互模式对标（2026-08-24）

> 归档说明：为 Nomi 内部 agent 模式收集的产品交互对标（MiniMax/海螺、小云雀、TapNow、LibTV、可灵、星流/Lovart），WebSearch/WebFetch 官方页优先，口碑取自横评/评测/issues。采纳决定见 `docs/superpowers/plans/2026-08-24-unified-agent-master-plan.md`。

## 1. MiniMax Agent + 海螺 Media Agent
MiniMax Agent（agent.minimax.io，2.0 桌面端）：纯聊天流+独立产物空间（设计/网页落外链或工作区文件，**无统一画布**）；模式分档 Lightning 快答 vs Pro 深做 vs 专家模式（注入私有流程做垂类分身）；按任务事后扣积分，**无生成前逐项报价**。口碑：网页/PPT 强，视频链路弱。**海螺 Media Agent**（hailuoai.com/agent）：视频专用，官方明确「成片链路任一 Part 都可在**画布**中与 Agent 调整细节，对话即创作」——MiniMax 自己把视频 agent 收敛到对话+画布双面。
→ 抄：模式分层（快/深/专家=可注入流程模板）。避：视频产物甩外链无画布。

## 2. 小云雀（字节/剪映，xyq.jianying.com）
短剧 Agent（Seedance 2.5）：对话发起，产物落**线性时间线视图**（剧本→角色/场景→分镜→成片），分镜脚本/提示词可编辑、单镜控秒；**先便宜后贵的阶梯确认**：剧本分镜文本近乎白给随便改，确认后才烧视频积分；明码 1 秒 5 积分。口碑差评集中：积分消耗快（一个月只做一集）、排队数小时、剧本被资深编剧评「没法用」、镜头准度差；横评垫底者（纳逗 Pro）死因=黑箱式、无法中止修改、积分不透明。
→ 抄：阶梯确认 + 每秒单价明码。避：线性流水线返工=整段重抽；黑箱/不可中止/积分不透明三条红线。

## 3. TapNow Creative OS（tapnow.ai）——确认交互全场最完整
架构=Agent+Apps+画布：⌘J 唤起对话框可**直接引用画布节点**；产物落画布节点；缺信息时**合并提问 ≤4 个**；**双生成模式随时切换**——「自动生成」（agent 定参直接跑，适合已明确长流程）vs「手动确认」（先出**可编辑确认卡片**：模型/比例/时长/数量，点生成才扣 Tapies，官方明示不免除消耗）；定向修改（「保留构图只把人物减到两人」）；交付前逐项检查。口碑正面居多。
→ 抄（最该抄）：自动/手动双模式+可编辑参数确认卡；合并提问。避：模式只管确认与否不管流程形态（分镜玩法靠用户自带提示词模板，没做成一等公民工作流）。

## 4. LibTV（liblib.tv）
产品内 Agent（2026-07-14）：一句话→三视图/分镜/视频+BGM 成片；**双视图**（工作流看进展 / 故事板打磨细节）；**级联修正**：点出错的图进 agent 上下文，修正后**系统给勾选表格让用户选哪些下游分镜重跑**，只重跑受影响节点；Agent Skill Hub（影视/广告/漫剧等技能可自建）。实测吐槽：节点强耦合一处错全链受染。**LibTV CLI**：外部 Agent 可创建「**可继续编辑的项目画布**」——官方承诺句式「交付的不是聊天回复或孤立视频链接，而是一张可继续查看/修改/复用的创作画布」。旧基线问题（黑盒改写 prompt 不可见、误建 43 项目）仍是反面教材。
→ 抄：级联修补勾选重跑；「交付一张可继续编辑的画布」承诺句式。避：黑盒 prompt；全自动放大错误级联。

## 5. 可灵 灵动画布 Agent 模式（快手，2026-01-30 随可灵 3.0）
画布底部对话框一句提示词→**AI 自动铺节点任务上无限画布**，节点连线成工作流、并行开跑、最多 5 人协作、一键整理画布；内置「故事目标→镜头拆解→输出优化」SOP；每节点按模型明码扣灵感值，**无 agent 级预算总览**。好评核心=终结工具跳转。
→ 抄：对话→自动铺节点→画布并行跑（与 Nomi 节点画布同构，验证方向）。避：SOP 藏系统里、无「这轮要花多少」总账。

## 6. 星流 / Lovart ChatCanvas（设计 agent 交互标杆）
右侧对话+中央画布；**ChatCanvas：直接在画布上标记元素/加注释发指令**（换图标/改配色），拆解可见、任务先反问范围再给参考候选；局部修改颗粒度不足（整图级）被骂；「扣点数不工作」是口碑杀手。
→ 抄：点选/标注即上下文（比文字描述「第三张图左上角」低一个数量级摩擦）。避：失败扣费不退；局部修改颗粒度不够。

## 跨产品收敛（行业答案）
1. **对话是方向盘，画布/结构化视图是路面**：6 家里 5 家收敛到「聊天框贴着画布、产物落画布节点、聊天只留过程」；纯聊天流+外链已被视频/设计场景淘汰。
2. **便宜步骤自动跑、贵步骤设闸**：闸的形态=一张**可编辑参数卡**（模型/时长/数量/预估消耗），不是 yes/no 弹窗。
3. **双视图成标配**：同一份状态给「看进度」和「改细节」两个镜头。
4. **局部返工=改上游+勾选重跑范围**；没有任何一家让用户整篇重生成还活得好。
5. **模式切换普遍存在但都做得浅**——「一个模式=一条完整流程+一套确认节奏」没人做成一等公民。

## Nomi 差异化机会
1. **把「模式」做成真正的流程合同**（选短剧/广告/MV 模式=锁定步骤序列、产物类型、确认点、预算节奏——playbook/gate 底子现成，对标里最接近的 LibTV Skill Hub 只是提示词包）。
2. **预算前置确认卡**（TapNow 有参数没总价、可灵有单价没总账；Nomi 波次生成前给「N 镜×单价=预估」一张卡、改参数实时重算——直击全行业最大骂点积分黑箱）。
3. **级联重跑+字段守恒双保险**（抄 LibTV 勾选交互，用 Nomi IR 保证重跑可对账）。
4. **prompt 可观测做成卖点**（用户写的/Agent 改写的/实发的三层摆在节点上；云端竞品因商业原因不给）。
5. **失败归因+是否计费明示**（用户自己的 API 额度——把「无补贴」劣势变信任优势）。

花费说明：纯 WebSearch/WebFetch，零生成额度。未能访问：知乎两篇 403、UIED 一篇；小红书/微博不可直接检索，口碑取自钛媒体横评等。
