# Agent 对话流「UI 词汇表」调研（2026-08-24）

> 归档说明：Opus 子 agent 逐家啃官方一手资料（DramaClaw 飞书手册 CDP 全文、TapNow docs 逐页、LibTV 官方指南存档、小云雀教程、可灵/MiniMax/星流官方页），校准 Nomi agent 对话组件词汇表草案。官方资料未覆盖的项均明确标注、无脑补。校准结论已并入 `docs/superpowers/plans/2026-08-24-unified-agent-master-plan.md` §4。

## 各家要点

**DramaClaw（虾导/虾条）**：对话是侧栏问答助理，不是主舞台；过程可见性全在独立任务中心「虾条」——**运行态词汇最完整的一家**：投递中/队列中/等待中/启动中/运行中/已完成/失败/已取消 + 取消/删除/清除 + **断点续跑**；「展开任务可查看日志、错误和结果」「点击跳转按钮回到任务对应页面」。花钱纪律是流程约定（「先搭后跑，视频花费高」）而非价格卡片。**反面教材**：手册评论区用户原话「虾条？虾导？为啥要将项目强行和龙虾绑定，感觉很奇怪？」——自造黑话增加认知负担。

**TapNow（与 Nomi 草案最同构）**：任务生命周期六段声明（读取上下文→确认任务→制定步骤→执行→定向修改→整理交付）；**合并提问**：「问题集中显示在输入框上方…下一题…提交…最多一次处理 4 个问题」；**自动/手动双生成模式**随时切换，手动=先出确认卡片（模型/比例/时长/数量/参考）+「生成」按钮才调模型——**但卡片不显示价格**（「手动确认只是让消耗发生在点击之后，不会免除消耗」），半诚实反例；产物写画布，对话用 +/@ 引用。

**LibTV**：对话在外部 CLI 宿主，画布是唯一真相源（「只返回一个视频链接，后续很难修改、追踪和复用」）；**错误修正闭环是标杆**：读报错→查节点态→判因（参数/引用/模型/素材/审核/临时）→改后重试，「不要重做整张画布，先定位失败节点」；脚本表格第一列**勾选批量重跑**；「先搭好完整画布结构，等我确认无误后再开始生成」。

**小云雀**：向导式流水线，双确认关卡（人景逐一查验+分镜审核通过才生成）；逐镜**悬停重做图标**；10-20 分钟美术准备期无过程可见性（「等待片刻」）——**黑箱等待反例**。

**可灵灵动画布**：指令→画布直接生成任务节点，「每一步工作在画布上实时查看」，**并行开跑多任务**；产物「添加到对话框」回填作参考。

**MiniMax/海螺**：过程可见性最重——思维链列步骤+列信息来源、「当前进程」窗、Files/Changes/Terminal 三面板；每对话=一个任务记录（历史/置顶/归档/轮次跳转）。偏专业 agent，重。

**星流/Lovart**：隐式后台分解不列清单；**单击产物→Tab 编辑栏→自然语言指令**局部重绘（「在产物上直接下指令」，摩擦最低的定向修改）；画布是产物主舞台。

## 跨产品对照（行=状态）

| 状态 | 共识/最佳实践 |
|---|---|
| 思考/规划 | 两极：黑箱（小云雀/星流）vs 重思维链（MiniMax）；中间点空缺 |
| 多步计划 | 声明式（TapNow）/固定向导（小云雀）/画布节点（可灵）；无人做可勾选动态清单卡 |
| 工具过程 | 任务条/节点实时更新（虾条/可灵）；对话内逐项文案无人展示 |
| 反问 | TapNow 合并提问 ≤4 问是唯一产品化案例 |
| 花钱确认 | 确认卡+点击才扣是主流；**没有一家卡上显示价格** |
| 产物 | 全行业共识：落画布/工作台，对话只留入口/缩略 |
| 失败 | LibTV 定位节点+判因+重试策略最完整；多数家无统一错误卡 |
| 进度/中止 | 独立任务中心（虾条 8 态）或画布节点；对话内原位进度无人做 |

## 对 Nomi 草案的校准结论

**共识确认（保留）**：产物=缩略卡跳舞台；反问=合并选项 ≤3 问（比 TapNow 的 4 更克制）；花钱=确认卡+暂停；工具=紧凑行；阶段=分隔线。

**Nomi 反着做更对的**：① **确认卡明标价格**（TapNow 藏价是半诚实反例，直击行业积分黑箱骂点）；② **思考条默认折叠可展开**（卡在小云雀黑箱与 MiniMax 过重之间）；③ 进度+停止**留在对话流原位**（别家都要跳任务中心/画布）。

**草案缺的五个状态（已采纳补入）**：① 任务前后态：排队中（第几位）/等待中/已取消（虾条 8 态启发；视频生成高峰排队常态）；② **产物行内动作「改这条/重跑”」**（星流 Tab 编辑/LibTV 勾选重跑/小云雀悬停重做——只解决「看」不解决「改」摩擦高于三家）；③ **失败条**：哪一步败+人话原因+下一步动作（重试/换模型/看日志）；④ **多候选并排组件**（可灵/星流并行铺候选是常态）；⑤ **写入回执**「已加 7 个节点 · 撤销」。

**命名纪律**：组件/状态名一律大白话自解释（思考条/进度条/确认卡），不造需要背的品牌黑话（DramaClaw 教训）。
