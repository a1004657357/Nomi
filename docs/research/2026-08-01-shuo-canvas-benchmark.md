# SHUO Canvas 0.7.0 对标实测（2026-08-01）

> 结论先行：SHUO Canvas（原 AI-CanvasPro，B 站 UP 主「阿硕」，闭源收激活费）与 Nomi 高度同构——节点画布 + 剧本工作室 + 3D 导演台 + Agent + 多渠道接入。**最值得学的是「剪辑体感」三件事：整条真帧胶片、画布内原地快剪、波纹式无空隙模型**；其余多数是方向验证而非能力差距。本文所有 SHUO 侧结论来自本机 0.7.0 真机把玩（CDP 驱动逐项操作验证），Nomi 侧结论来自 main 代码逐文件核对（附 file:line）。

## 一、对手是什么

- **形态**：Electron 桌面 App（Win/mac arm64），内置本地 sidecar 后端 `aicanvas-backend`（127.0.0.1:8777，媒体处理/文件管理跑在这里，前端从它加载）。
- **商业**：不开源（GitHub 仓库只有 README/协议，release 挂安装包）；收「软件激活费」+ VIP 限定功能（替换工作室、自定义中转、部分工作流），每家 API 平台链接都带邀请码返佣。模型费用用户直付各平台。
- **迭代**：release notes 显示节奏极快（半年 30+ 版本），功能广撒网（对口型/去字幕/数字人/游戏制作教程都有），典型「一人快跑 + 社群驱动」。
- **工作区**：画布模式（节点创作）/ 剧本工作室 beta 限免（剧本→分镜→成片）/ 替换工作室 beta VIP（跨镜人物替换）/ 3D 场景预演；外挂语音工作室（识别字幕→翻译→批量克隆配音）与右下角 Agent。
- **节点分类**（双击画布菜单实拍）：生成节点=文本/图像/视频/音频；功能节点=3D导演台/360全景图/宫格图/分镜脚本/拼图/白板/**剪辑**/注释；上传文件。
- **接入**：固定厂商栅格（APIMart/Agnes/火山方舟/豆包语音/RH 国内外/GRSAI/PPIO/ComfyUI 本地云端/OpenAI 兼容/自定义中转），每家带「国内线路1/2/海外线路」手动切换 + 获取 Key 链接 + 测试连接。ComfyUI 自定义=粘贴 workflow_api.json → 逐行勾选要暴露的输入 → 生成节点。

## 二、剪辑对比（重点）

### 2.1 他们的「剪辑节点」——真机逐项验证

接入：节点空态一句引导「轻点鼠标连线按钮，在画布上选取视频、图片或者音频」；**「继续添加片段」可把多个素材串成一条序列**（它是序列组装器，不是单клип裁剪器）。

| 维度 | 实测行为 |
|---|---|
| 形态 | 节点内=时间标尺（2s 刻度）+ **整条真帧胶片**（全程缩略图）；DOM：`media-clip-timeline-scroll > tracks > segment > filmstrip` |
| 预览 | 单击胶片即在节点上方展开大预览（画布内、非弹窗），预览跟随播放头 |
| 播放头 | **双播放头**：hover 幽灵播放头跟鼠标 + 单击落真播放头；Space 播放/暂停（双 `<video>` 预载下一段） |
| 分割 | `C` 剪开播放头处素材（实测 1 段→2 段） |
| 裁剪 | 段两端 trim 手柄（18px 热区/5px 视觉条）；**波纹模型：裁掉即合拢、总时长实时缩（12s→10s）、不存在空隙** |
| 重排 | 拖段换序（实测两段互换成功），底部滚动提示逐条教学 |
| 删除 | Delete 删当前素材 |
| 滚动/缩放 | 滚轮=胶片横滚（内容可超宽 `has-right-overflow`）；修饰键+滚轮=缩放时间线 |
| 出口 | ⬇️ 下载成片；**右键「导出素材到画布」→ 选中段变成新视频节点回流画布**（实测成功，toast「素材已导出到画布」）——剪完的东西能继续喂生成节点 |
| 底层 | 媒体处理走本地后端任务中心（「提取视频首帧」「生成视频封面」任务可见，自定义协议 `aic-local-preview://` 喂预览） |
| 没有的 | 多轨、字幕/标题、转场、变速、音量/波形——**它是单轨快剪，不是成片台** |

视频节点自身工具条（选中浮现）：裁剪视频/语音工作室/视频倒放/提取关键帧/抠像/分镜脚本/人脸检测/更多/全屏/上传/下载。

### 2.2 我们的时间轴——main 代码核对

有（且不少做得比他们深）：三媒体轨+文字叠加层（`timelineTypes.ts:62`）、offset 模型 trim（`timelineEdit.ts:392`）、`S`/剪刀模式分割（`TimelinePanel.tsx:181/311`）、拖拽滑入空位不弹回（`timelineEdit.ts:108`）、多选成组、复制/逐帧微调、**吸附子系统**（磁吸虚线+咔哒反馈，`timeline/snapping/`）、标尺+缩放（0.35–4×）、取景 WYSIWYG（`framing` 导出复现）、字幕/标题卡烧录导出、音频轨可拖可裁+导出自动混音、**clip 就地重生成**（`TimelinePanel.tsx:285`，AI 原生差异点，对手没有）。

没有（06-21 方案里多数是有意砍的）：变速、转场、单 clip 音量/淡入淡出、波纹删除、波形、JKL/IO。

### 2.3 体感差距的真因（为什么用户觉得他们「好用」）

1. **内容可见性**：我们出于性能只给「单选中 clip」挂真帧，其余是色块+名字标签（`TimelineClip.tsx:35-38, 269-275`）——扫一眼认不出哪镜是哪镜。他们全程胶片。**他们的解法不是硬扛 N 个 `<video>` seek，而是后台预生成缩略图（任务中心可见），渲染层只贴静态图**——我们的性能顾虑可以被同一架构解掉。
2. **入口距离**：「拿到生成结果先掐头去尾/取一段」是高频微动作；他们在素材旁边原地剪，我们要切到预览页时间轴（画布视频节点零裁剪能力：全仓 `trimVideo/裁剪视频` 无命中，仅有提取关键帧 `extractVideoFrameToNode.ts`）。差一屏。
3. **模型心智**：他们=波纹（永远无空隙，剪完即成串，适合快剪）；我们=自由摆放（可留空隙，适合成片编排）。不是谁对谁错，是**快剪场景我们没有对应形态**。
4. 交互细节：hover 幽灵播放头、点胶片任意处 seek（我们点 clip 只跳 clip 头，`TimelineClip.tsx:342`）、点击即出大预览。

### 2.4 学习方案（建议，均需样张拍板后做）

- **L1 时间轴胶片化（最高优先）**：per-媒体后台预生成缩略图条（ffmpeg tile 一次、缓存本地），`TimelineClip` 全员贴真帧裁剪显示。修差距 1，纯渲染架构改动、不动数据模型。
- **L2 交互三小件**：hover 幽灵播放头；点 clip 内任意位置 seek 到光标帧（替代仅跳 clip 头）；（吸附/气泡我们已有，保持）。
- **L3 画布快剪下放**：**不做**平行「剪辑节点」（P1 红线：我们已有真成片台，再造一个单轨编辑器=并行版）；把 trim/split/取当前帧做成**视频节点结果上的原地快剪**（写入 result meta 单源，时间轴 clip 与下游引用继承裁剪）。修差距 2，同时喂强「画布↔时间轴双向绑定」这个我们独有的结构优势。
- 波纹模型不整体引入；在时间轴加「删除并合拢」这一个算子即可覆盖 90% 波纹诉求（此前方案标延后，可重新排期）。

## 三、剧本工作室（对照我们的 创作→画布→时间轴 主链路）

结构（showcase 截图 + 真机 landing 实拍；生成需 API key 未跑通全程，标注为观察）：

- 入口双轨：**上传剧本文件（TXT/DOCX/文本型 PDF ≤10 万字）** 或 AI 写故事（≤5000 字设定 + 集数 + 剧情模式）。
- 全局配置：模型 + **风格预设墙（100+ 命名风格，全部/真人/2D/3D 分类：宫斗权谋冷峻/古偶唯美柔光/90年代港片/大友克洋/上美画风/皮影戏…）** + 每镜时长 15/30 秒。
- 编辑器（观察）：左=资产列表（角色/场景卡）；中=分集脚本，**实体芯片内联在文本里**（@角色/@场景 彩色 chip，分镜块带时长与台词）；右=成片播放器；底=「片段01–09」横条（每段缩略图+时长+总时长，点击切换中间提示词与结果，同卡多次生成有历史可切）。
- 与我们的差异：他们是**页面级线性流水线**（脚本→逐段生成→片段条串片），我们是**画布自由结构 + 一键拼片进成片轨**（`arrangeStoryboardToTimeline`）。他们的「片段条=导航器」轻快；我们的时间轴=真成片（可字幕/混音/导出）。结构上我们更完整，他们上手更傻瓜。

## 四、其他学习点速查

| 他们的做法 | 我们的现状 | 学不学 · 理由 |
|---|---|---|
| 风格预设墙（100+ 中式短剧语系命名风格） | 提示词「我的库」+ 无内置风格包 | **学**：走现成 builtinPacks 机制出「风格包」，注入分镜方案/生成提示词。便宜、贴短剧 WHO |
| 剧本文件导入（docx/pdf→分镜） | 已有方案文档（creation-ai-attachments，docx/xlsx 混合路由待做） | **学**：对手已验证需求，建议提优先级 |
| Agent 快捷四钮：梳理画布/**补齐链路**/生成分镜/优化选中 | Agent 工具齐但入口=纯聊天框 | **学**：effect-first（D1），把高频三四个动作做成 composer 上方 chips；「补齐链路」概念极好（扫画布缺哪环自动补） |
| @语言化引用（1–12 素材，提示词里写「@图1 模仿 @视频1 的动作」） | 连线=结构化引用槽 + 能力校验 + L3 拒发闸 | **不学整套**：语言化依赖模型自觉、静默失败风险高，与我们「发不出就拒发保钱」哲学冲突；保留结构化。可借鉴：提示词里可读的引用名（我们已有有序单源，差「在 prompt 里可见」一步） |
| 线路切换（国内1/2/海外手动选） | apimart 候选域自动探测回切（apimart-gfw-fallback） | **不学**：我们自动化更优；已有应用内代理三态行 |
| 剪辑节点整体 | 预览页成片时间轴 | **不学形态、学三个体感**（见 2.4；避免并行版） |
| 替换工作室（逐镜检测人物→指认→批量替换） | 跨镜身份是既定护城河方向（ViMax 借鉴、角色定妆图） | **方向验证**：对手把它做成独立工作室=市场确认；我们按画布语义做（角色卡+批量重生成），不抄页面形态 |
| 语音工作室（识别→翻译→批量克隆配音） | 豆包 TTS 已接、音频节点/音频轨已有 | **半学**：他们服务影视二创（重配他人视频）；我们 WHO 是原创短剧——该做的是「分镜台词→批量 TTS→对轨」原创配音链，不是二创重配 |
| ComfyUI 勾选暴露输入→生成节点 | 本地 ComfyUI 已接 + 自定义 workflow 已拍板待建 | **学 UI 手法**：「逐行勾选要暴露的参数」这个交互直接可抄进我们的自定义 workflow 导入 |
| 本地 sidecar 后端做媒体任务+任务中心 | 主进程 ffmpeg IPC + 任务在节点内 | 架构等价不折腾；「后台任务中心」面板可在批量场景再评估 |
| 收激活费+VIP+全渠道返佣 | 免费开源 + apimart 返佣 | 商业观察：证明画布类工具「软件费+返佣」双轨在国内跑得通；我们暂不动，留作变现参考 |

## 五、明确不学清单（防散焦）

- 宫格节点/拼图节点/360 全景（我们有）/白板（我们有画板）——同质，不追加。
- 对口型/去字幕/抠像/人脸检测等 RH 工作流搬运——供应商能力转售，广度是敌人（D2），我们按「模型身份+通用槽」接，不逐个做按钮。
- 多画布标签页——我们的项目模型已覆盖。
- 默认画布预置 3D 导演台节点——首启体验反而被它抢焦点（真机里它吞掉一切双击，教训：大型交互节点别做默认预置）。

## 补充（当日晚·Nomi 侧真机走查实录）

对 Nomi 自身跑了同旅程真机走查（隔离实例 + 4 段本地视频 → 组装 30s 成片），推翻了上文一个假设并挖出一个 P0：

- **P0（已修 c2fa668a）**：视频/音频 clip 裁剪在生成页与预览页 UI 上"纹丝不动"，但 store/落盘/导出已按裁剪走——根因 `TimelineClip.tsx` 宽度绑 `clip.frameCount`（源总长，上古读点），6 月引入 offset 裁剪模型后视频/音频 trim 只改 offset+endFrame。视觉跨度≠真实跨度还使按视觉位置的分割落进"幽灵区"被守卫静默 no-op——**用户感知即"裁剪/分割全是坏的"**。修=抽 `clipVisibleFrames` 单源（宽度+剪刀范围）+ 回归测试；真机复验裁剪跟手、分割生效。
- 上文 §2.3"体感差距"三条仍成立，但权重重排：真机下最痛的是 ①剪辑无画面反馈（生成页时间轴无预览，盲剪；预览页有画面但丢画布上下文）②自由摆放税（拖放落点字面化→随手拖=空隙；重叠拖放被拒 toast 让用户自己找空位；拖放不吸附）③空隙进播放头显示全局空态文案「从生成区拖入素材即可显示」（有素材的用户会懵）。
- 微摩擦实录：「拖拽到时间轴」按钮样式不可点击（死点击零反馈）；点 clip 播放头跳 clip 头非点击处；trim 手柄 12px 且选中才出现；项目卡封面对本地素材项目显示「加载失败」。
- 走查证据：/tmp/nomi-uxwalk/shots/n01–n28（临时目录）。
