P48: 如何使用Skill？
P49: 方法一：在广场直接试用
 在 Skill 广场或我的技能中，选中想用的 Skill，点击「去对话中试试」，就能直接调用。
P50: 方法二：/ 快捷键调用
 在对话框输入 /，选择想要的 Skill，明确告诉 Agent 你要用哪个。选定后，跟着 Skill 的引导一步步操作就好了。
P51: 方法三：直接和Agent 询问匹配
例如，你可以在对话框：“我要做一个批量 KOC 美食吃播视频，请帮我调用相应的 skill 完成。”Agent 就会调用「批量 KOC 」的技能。
P52: 方法三：Agent 自动调用
 对于已经开启的 Skill，Agent 会根据你的对话内容自动判断该用哪个。
比如你开启了「海报设计」这个 Skill，当任务涉及到制作海报和图示能力时，Agent 会自动调用它，直接写出高质量的提示词——不需要你手动触发。
P56: 方法三：从提示词模板开始
P57: 不会写提示词，或觉得专业提示词太长、太复杂？MiniMax Design 提供了针对不同创作场景优化的提示词模板。你只需用简单、自然的语言描述需求，即可获得接近专业长提示词的高质量生成效果。
P58: 使用方法：在模板广场中找到合适的模板，点击「使用提示词」，再根据自己的产品、场景和风格修改相关内容，即可开始生成作品。
P59: 生成后，你可以随时与 Agent 对话，对画面、文案、节奏和细节进行进一步调整。

P148: 基础介绍
P149: MiniMax Design 基于 MiniMax H3 开源模型，开放本地部署与 ComfyUI 工作流能力。用户可以在自己的设备上运行部分视频生成流程，并将 H3 的视频生成能力接入 Design 的画布与 Agent 创作流程中。
P150: Design 进一步把 H3 的模型能力封装成可下载、可运行、可调整的精选工作流，让用户不必从零搭建复杂的 ComfyUI 流程，也能更低成本地开始本地创作。
P151: 目前，Design 已配备多套「官方精选工作流」，覆盖文生视频、首尾帧、多参考、超清、扩写、人像增强等不同能力。你可以根据电脑配置、创作需求和成本偏好，选择轻量版、满血版，或带有官方超清、扩写等增强能力的版本。轻量版更适合快速体验和普通设备运行；满血版效果更完整，但对显存、内存和本地存储要求更高。
P153: 基础使用步骤
P154: 1｜选择工作流
P155: 进入开源与部署页面，浏览官方精选工作流。你可以查看每个工作流的适用场景、输入要求、配置建议、局限性、依赖文件、来源与许可信息，再根据需求选择下载。
P156: 2｜下载并管理工作流
P157: 下载后的工作流会进入“我的工作流”。在这里，你可以查看已下载内容，并选择直接在画布中使用。
P158: 3｜在画布中运行
P159: 点击“使用”后，Design 会在画布中创建对应的 ComfyUI 工作流节点。普通用户可以直接修改提示词、上传输入素材并等待输出；有 ComfyUI 基础的用户也可以展开自定义节点，查看或调整更完整的工作流结构。
P160: 4｜与画布和 Agent 联动
P161: 本地工作流的输入和输出可以与画布联动。你可以把画布上的素材作为上游输入，也可以把生成结果继续用于后续编辑、视频生成、包装或案例制作。Agent 也可以识别工作流，理解它的用途，并帮助你调用它完成具体创作任务。
P162: 5｜导入或新建工作流
P163: 除了官方精选工作流，你也可以导入社区分享的 ComfyUI 工作流文件，或新建空白工作流，自行搭建节点流程。这一部分更适合熟悉 ComfyUI 的专业用户和开发者。
P171: 补充帮助：商业内容制作
P172: Q：如何写好需求？
P173: 在 Design 中，写好需求的关键是从「描述画面」升级为「表达商业目标」。需求描述得越清晰，Agent 生成的内容就越贴合你的预期。

3.多技能Skill协同：TVC、品牌与资产生成
在短片制作过程中，Agent 根据需求动态调用多个专业 Skill 协同工作：
TVC 技能：用于规划短片的整体叙事节奏和镜头语言，确保各段节拍分配合理、转场流畅。
品牌技能：负责锁定图形风格模板、品牌图形规范和视觉调性，保证成片风格与品牌调性一致。

Agent 先生成精确节拍与文字分镜表，明确每个时间节点的画面、人物运动方式、图形切换时机和转场节奏。
用户确认后，按分镜逐段调用 MiniMax-H3 生成各段视频，每段使用对应的锚定照片作为参考图。
所有片段生成完毕后，按分镜顺序拼接成完整短片，总时长约 1 分多钟，并统一配乐和节奏卡点。

6.最终产出
