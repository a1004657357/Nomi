P52: 常见问题
P53: 1. 我需要学命令行吗？
P54: 不需要。
P55: CLI 是给 Agent 用的。你只需要安装和登录一次，后面继续用自然语言描述创作需求。
P56: 2. 登录和使用积分还需要 Access Key 吗？
P57: 不需要。
P58: LibTV CLI 可以直接在 Agent 中触发浏览器登录。你在浏览器里完成登录后，登录状态会返回给 Agent，之后 Agent 就可以使用这个已登录账号在授权范围内使用积分以及进行创作了。
P59: 3. 积分消耗如何计算？
P60: 通过 LibTV CLI 或 Skills 发起的调用，将使用所登录账户的积分，和你在画布中生成对应节点消耗的积分相同。
P61: 4. 如何在 CLI 中切换团队/个人空间
P62: CLI 的登录状态依赖你登录 CLI 时浏览器里的 LibTV 登录状态。
P63: CLI 使用的账号和空间，也同样依赖你登录 CLI 时浏览器中的账号与空间状态。也就是说，你在浏览器里切换账号，或者切换团队空间 / 个人空间，都会影响 CLI 后续的登录状态、可访问项目和操作权限。
P64: 如果你希望 CLI 使用指定的个人空间或团队空间，建议先在浏览器里切换到对应账号和空间，再进行 CLI 登录或重新登录。同时，也建议把希望切换到的「个人 ID」或「团队 ID」复制给 Agent，让 Agent 帮你核对浏览器当前登录状态、空间状态和你期望 CLI 使用的状态是否一致。
P65: 5. 为什么 Agent 使用 CLI 时偶尔会报错？
P66: LibTV CLI 内部提供的项目、画布、节点、素材、模型调用、状态查询等基础能力是比较完整的。但 CLI 是给不同 AI Agent、不同模型和不同脚本工作流调用的，实际使用中出现报错，不一定代表 CLI 本身缺少能力。
P67: 常见原因包括：
P68: Agent 没有正确理解需求或当前画布状态
P69: 模型把参数、节点类型或引用关系写错了
P70: prompt 没有说清楚生成目标、参考图用途或视频节点要求
P71: 自定义 Skill / 脚本没有按 CLI 的真实命令和参数调用
P72: 当前模型对复杂多图、多角色、多步骤任务的理解能力不足
P73: 生成任务遇到安全审核、模型异常、网络波动或临时服务不稳定
P74: 遇到这类情况，建议先让 Agent 做一次诊断：
P75: 读取报错信息和失败节点
P76: 查询项目、节点和任务状态
P77: 判断问题更像是参数、引用、模型、素材、审核还是临时异常
P78: 修正脚本或 prompt 后重试
P79: 很多问题通过多诊断一次、多试几次，或者把需求说得更具体，就可以解决。如果连续多次失败，再把项目链接、节点信息、报错内容和操作步骤一起反馈给官方，方便定位。
P80: 6. 为什么一定要把过程放到画布？
P81: 因为视频创作不是一次性文本回复。
P82: 画布可以保存：
P83: 脚本
P84: 分镜
P85: 参考图
P86: 视频节点
P87: 上下游依赖
P88: 失败节点
P89: 可继续编辑的中间结果
P90: 只返回一个视频链接，后续很难修改、追踪和复用。
P91: 7. 生成任务很慢怎么办？
P92: 视频生成本身可能需要较长时间。短视频任务通常也可能等待十几分钟到更久，高峰期会更慢。
P93: 建议：
P94: 先确认 Agent 已经把项目和节点创建好
P95: 让 Agent 查询节点状态，而不是重复提交任务
P96: 长任务可以后台等待，过一段时间再让 Agent 检查结果
P97: 8. 失败会扣算力吗？
P98: 具体以 LibTV 当前产品规则为准。一般生成失败、审核拦截、模型异常等场景可能有返还机制，但不要把“失败一定不消耗”当成固定承诺。
P99: 如果遇到疑似误扣，保留项目链接、节点信息、任务时间和失败原因，再反馈给官方。
P100: 9. 如何取消登录、解除绑定和授权？
P101: 你可以直接对已连接 LibTV CLI 的 Agent 说：
P102: LibTV CLI 取消登录，解除绑定和授权。
P103: 或者
P104: libtv project unuse
P105: libtv logout
P106: Agent 会清除本机 CLI 登录凭据，并解除当前工作目录与 LibTV 项目的绑定。完成后，可以让 Agent 验证：
P107: CLI 是否已经无法读取当前账号信息
P108: 本机登录凭据是否已经被删除
P109: 是否还能继续读取项目列表或操作画布
P110: 如果取消后 CLI 已经提示未登录，且当前目录没有项目绑定，说明这个 Agent 已经不能再使用你的 LibTV 账号继续操作。
