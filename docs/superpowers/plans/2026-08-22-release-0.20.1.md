# Nomi 0.20.1 Release Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Prepare a clean `0.20.1` release candidate from `origin/main`, documenting and packaging the recent canvas, media-preview, MCP, and production-pipeline fixes.

**Architecture:** Keep the release scoped to version metadata and release documentation; do not alter runtime behavior in the release branch. The release candidate must be built from the clean `origin/main` baseline and must pass the repository release contract before any tag/promotion step.

**Tech Stack:** Electron Builder, Vite, TypeScript, pnpm, GitHub Actions release-contract checks.
