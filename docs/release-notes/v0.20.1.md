# Nomi v0.20.1

v0.20.1 是一次以真实用户反馈为入口的稳定性与生产链收口版本，基线为 2026-08-21 的 `origin/main`。

## 这次最重要的变化

### 1. 画布反馈真正闭环

- 右键空白可以添加节点，右键节点可以操作；复制入口不再藏在用户找不到的快捷键里。
- Cmd 与 Ctrl 的复制、粘贴、撤销、删除路径统一；菜单项点击不会再被画布事件提前卸载。
- 大量素材、低缩放浏览时仍保留轻量预览；本地 `nomi-local://` 媒体流不再重复包装网络流。
- 九宫格/四视图切图不再把大图 base64 塞进状态：切片会逐步落盘、摊成独立节点、自动编组并自动 fit，整次切图可一次撤销。
- ComfyUI 等导入工作流的参数摘要显示参数名称，减少“勾了但不知道是什么”的困惑。

### 2. 外部 Agent 可以把制作草稿推进到可审片

- MCP 工具扩展到 22 个，增加 brief 收敛、本地素材导入、分镜物化、结果缩略图、深链和安全预览。
- 增加定妆锚/首尾帧锚定、冻结门、镜头语言字段，以及审片评分、定向重试和红标交付。
- Production Run 支持从剧本到分镜、画布、时间轴、字幕和 MP4 的持久化合同，并能在重启后恢复。

### 3. 创作与模型配置更顺手

- 增加 Prompt 选择器、自定义 Prompt、系统提示词设置和分镜批量修改。
- 新建节点默认模型选择和启动挑模更稳定；修复中文输入 `@` 引用参考图；刷新 DeepSeek 文本模型。

## 升级说明

- 现有项目、设置和已保存模型配置沿用原数据目录。
- 当前正式包只提供 macOS arm64、macOS Intel 和 Windows x64。
- macOS 包未签名、未公证；Windows 包未使用 Authenticode。首次安装请按 README 的系统提示操作。

## 已知边界

- draft-film 验收使用已有 launch film 素材，验证的是生产合同、字幕、转场元数据和 MP4 导出，不代表新 provider 生成的画面质量。
- 当前非硬切转场仍只保存为时间轴元数据，导出器尚未把 `dissolve`/`fade` 渲染成视觉 xfade。
