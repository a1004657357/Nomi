# Nomi v0.20.0

v0.20.0 把 Nomi 从“单次生成工具”继续推进成可恢复、可验收的 AI 视频生产工作台。这一版包含 v0.19.0 之后的 185 个提交。

## 这次最重要的变化

### 1. 外部 Agent 可以更可靠地把任务做完

- 生产运行现在有持久状态，Nomi 重开后仍能恢复任务上下文。
- 创意方向、首镜抽检、预算和信任等级变成明确关卡，不再靠聊天文字猜是否获批。
- 运行支持暂停、恢复、取消与后台提醒；MCP 会返回简洁状态、可行动错误和最新安全预览。
- Codex、Claude Code、Cursor 等宿主的打包启动路径与真实服务旅程得到加固。

### 2. 模型接入从“填完配置”变成“保存后能恢复”

- 模型统一在设置页管理，先保存，再验证；验证失败会保留配置并明确告诉你下一步怎么处理。
- 自建/局域网端点、无 Key 服务、中转站和自定义调用得到更完整的能力探测与错误说明。
- 自定义调用的命名配置迁入系统安全存储；无 Key 的 OpenAI-compatible 端点不再携带空的 `Authorization` 请求头。
- 新增 APIMart Seedance 2.5、Gemini 3.5 Flash 等档案，补齐首尾帧、多参考素材和自定义参数契约。
- ComfyUI 通用工作流、模型选择和生成结果解析更稳，并加入真实用户接入旅程回归。

### 3. 画布到剪辑的操作链更完整

- Clip 节点支持核心剪辑动作，裁剪手柄和时间轴拖拽会真实跟随指针。
- 时间轴按内容增长，视频首帧、悬停预览、播放和导出前的媒体状态更可靠。
- 大型画布只为当前可见媒体保留渲染资源，降低占用，同时确保滚动到视口的内容立即可见。
- 节点工具栏、连线、图片编辑、复制粘贴和布局完成一轮一致性修复。

### 4. 桌面更新与下载链正式收口

- 修复窗口重开、保存对话框、浏览器菜单和进程 stdio 等桌面稳定性问题。
- 新的 RC → 正式版流程会发布同一批已验收产物，避免“验收的是 A，发布时又重建成 B”。
- 官网提供 Apple Silicon、Intel Mac 和 Windows x64 的固定下载入口；应用内检查更新会跳到正确架构。

## 安装包

- macOS Apple Silicon: `Nomi-mac-arm64.dmg`
- macOS Intel: `Nomi-mac-intel.dmg`
- Windows x64: `Nomi-windows-setup.exe`
- 校验文件: `SHA256SUMS.txt`

## 升级说明

- 正式版沿用现有 Nomi 用户数据目录，项目、设置和已保存模型配置会保留。
- Preview 使用独立应用标识和项目目录，不参与 stable 自动更新。
- 当前仅发布 macOS arm64/x64 与 Windows x64，不提供 Linux、Windows arm64 或 macOS universal 包。
- macOS 安装包未签名、未公证；应用内更新会打开匹配机器架构的下载页，需要下载 DMG 后手动替换应用。
- Windows 安装包未使用 Authenticode 签名，首次安装时可能出现 SmartScreen 提示。
