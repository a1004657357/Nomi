# Nomi v0.22.3 — 参考图与画布比例修复

**正在用 v0.22.2 的用户，直接升级这一版。** 这是一个只包含已验证修复的轻量版本。

## 修好了什么

### 参考图误判

部分合法的 GPT 生成 PNG 带有 C2PA/XMP 元数据，元数据内部可能出现 SVG/XML 片段。旧逻辑在文件前 2 KB 的任意位置寻找这些文本，于是把合法图片误报成 HTML/XML/SVG，图生图会在参考图阶段失败。现在只按真实媒体结构判断，合法 PNG/JPEG 可以正常作为参考图；真正无效的素材会显示为素材无效，不再误报服务商故障或额度问题。

### 图片节点自动比例留白

生成资产的原始宽高在结果落地时曾丢失，而画布显示的是缩略图，缩略图尺寸不能代表原图比例，所以自动比例节点会出现留白。现在原始宽高会随结果进入共享媒体元数据边界，普通生成、恢复、制作流程、历史版本切换和存量项目回填都使用同一套比例信息。

### 稳定标签流程

开发钩子不再拦截已经存在于远端分支历史的提交，`v0.22.3` 可以通过 Desktop Release 正式流程创建。
