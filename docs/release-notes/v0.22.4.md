# Nomi v0.22.4 — APIMart 出图落地与连接修复

**正在用 v0.22.3 的用户，直接升级这一版。** 这是一个只包含已验证修复的轻量版本。

## 修好了什么

### 生成好的图片、视频拉不回本地

部分 APIMart 模型（例如 Seedream）的异步结果，把图片或视频地址直接给成一个字符串；旧逻辑只认「地址是一个数组」这一种形态，于是取不到地址，节点一直停在「正在存到电脑上」。现在两种形态都能正确取到，结果照常存到本地项目里。

### 「连不上服务商」

在和 APIMart 建立加密连接的阶段，网络偶尔会把连接重置（`ECONNRESET`），表现为「连不上服务商，请求没发到服务商」。现在这种情况会自动换到 APIMart 官方备用域名重试一次。只有**请求还没发出去**时才会重试；请求一旦已经送达，就不再重发，避免同一次生成被扣两次钱。

### 画布卡片上的多余小字

删掉了卡片上「画布改的：…」这类没有行动价值的提示；分镜表里对画布改动的采纳 / 丢弃按钮保留。

## 验证

- PR #914 的必需门岗（Contracts、Unit、E2E、Canvas Acceptance、Canvas Performance、Core Flow Smoke、Mac Package）全部通过；合入后在真实合并提交上两遍核心冒烟通过。
- 回归测试覆盖：APIMart 图片/视频结果的字符串与数组两种形态；只对建连前的连接重置换线重试。
- Cloudflare Workers Builds 的外部构建失败与本版本代码无关，沿用仓库既有已知状态。

AI 工具连着 Nomi 时窗口反复弹出的修复、连上参考图后默认用参考模式、「几版」改成可展开的版本卡片、React 19 升级，都在后续版本推进。
