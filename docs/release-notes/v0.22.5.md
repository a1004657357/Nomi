# Nomi v0.22.5 — APIMart 可以改成国内接口地址

**正在用 v0.22.4 的用户，直接升级这一版。** 这是一个只包含已验证修复的轻量版本。

## 修好了什么

### APIMart 改不了接口地址

新电脑上把 APIMart 改成国内地址时，保存会报一句英文错误，不会翻墙的用户就用不了。现在在「设置 → 模型 → APIMart」里填 key 的地方就能直接改地址，保存即生效，已存的 key 会跟着新地址走。国内线路请填 `https://api.apib.ai`。地址连不上时的提示也改成了中文，不再夹着英文原文。

### 做过「自检」之后 Agent 生成不了

在 APIMart 下手动加过模型、点过「继续验证 → 自检」的话，画布能出图，让 Agent 生成却一直提示「这一步没成」。现在自己加的那个模型只影响它自己，Agent 和画布一样能用。

## 验证

- 用安装包本体走查：改地址、保存、重开后地址保留、画布出图、Agent 出图，请求全部走国内线路。
- 回归测试覆盖：设置页保存地址、自检之后的连接归属判定、Agent 生成路径。

## 本版不包含

界面、模型清单和其他功能没有变化。
