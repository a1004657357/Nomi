# Nomi v0.22.0 — 画布、分镜与 Agent 制作链收口

这版对照 v0.21.0 到当前主线的真实合入记录整理，重点是把“画布操作 → 分镜计划 → Agent 执行 → 素材与导出”这条主链上的断点补齐。

## 画布与剪辑

- 拖入素材会落在松手位置；Alt 拖动复制、快捷键和连线把手的行为保持一致。
- 画布平移后，参数浮框、版本托盘和编组框操作仍然可见、可用；生成浮框不再被底部控件遮住，快速输入不再丢字。
- 图片比例、镜号身份、视频拆解切点和 Clip 导出完成状态得到修复；剪辑走查覆盖拖动、预览、裁剪、导入、导出、撤销和取消。

## 分镜与 Agent

- Agent 写入的分镜计划现在有可见的分镜表记录；拆解节点会正确进入终态，不再永久停在“拆解中”。
- 分镜选择的模型身份贯穿请求和价格；同域名下的多条连接可以独立管理。
- “用 AI 帮我接入”通过声明卡完成模型接入；工具展示直接投影宿主契约，减少模型看到的字段与实际能力不一致的情况。

## 模型、凭据与技能

- 保存凭据时优先使用免费验证；需要可能计费的验证会先向用户说明并等待确认。
- 外部技能加载对齐现有 pi 宿主，技能可以从外部包安装并进入 Agent 会话。
- 供应商连接不会因保存或读取路径丢失声明字段；连接断开、取消和失败会留下明确终态。

## 可靠性

- 画布、Agent、分镜、MCP 和桌面打包的真实 Electron 旅程补齐了回归覆盖。
- 发版候选会收集所有关键旅程的结果和证据，再统一判定；单条失败不会遮掉后面的阻断问题。

## 诚实边界

- 模型是否可用仍取决于用户自己的供应商凭据、账号权限和上游额度。
- 本版没有改变非硬切转场的导出限制；`dissolve`、`fade` 等仍按既有时间轴元数据处理。
