# Nomi v0.23.2 — 视频取回热修

这一版是热修，处理两件事：视频在服务商那边已经做好、Nomi 却取不回来；以及让 Agent 生成视频时，偶尔点了「生成」没反应。

## 修了什么

- **做好的视频能取回了**：以前视频在服务商那边已经出片，Nomi 却停在「任务可能已在上游完成」，点重新拉取也没用。现在会正确读到结果、落到节点上，不会再把提示里带回来的参考图当成结果。
- **取不回时说清卡在哪一步**：查询失败、服务商说法对不上、拿到的文件类型不对，现在都会写明是哪一步出的问题和最后一次的原话，不再只给一句笼统的话。
- **「重新取回」只查结果，不会再扣一次钱**：它只去问服务商要已经做好的结果，不会重新提交任务。
- **文件类型不对不会混进素材**：存进项目前会按这个任务该出的类型（图片或视频）核对一遍，对不上就不收。
- **Agent 生成视频偶尔点了没反应**：常见的那种原因修好了；还生成不了的，卡片会说清是哪个参数、怎么办。

## What changed

- **Finished videos are retrieved**: Previously a video could be finished and paid for at the provider while Nomi stayed on “the task may have finished upstream” and re-fetching did nothing. Nomi now reads the result correctly and lands it on the node, and no longer mistakes an echoed reference image for the result.
- **Clear reasons when retrieval fails**: A failed query, an unexpected provider reply, or a file of the wrong type now says which step failed and shows the last error, instead of one generic message.
- **“Retrieve again” only checks the result and never charges again**: It only asks the provider for the finished result and does not submit the task again.
- **Wrong file types stay out of your assets**: Before a result is saved into the project, its type is checked against what the task was meant to produce (image or video); mismatches are rejected.
- **Agent-drafted video occasionally did nothing on Generate**: the common cause is fixed; if a generation still can't start, the card now names the parameter and what to do.
