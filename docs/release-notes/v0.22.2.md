# Nomi v0.22.2 — 修好 Agent 长任务时界面卡死

**正在用 0.22.1 的用户，直接升级这一版。** 只修了一个问题，其他没有变化。

## 修好了什么

有 Windows 用户反馈：让 Agent 跑长任务时，界面会卡住几秒到几分钟，点不动，Agent 的回复也出不来，严重时只能结束进程。

原因：对话越长，Agent 每吐出一段字，界面就把整段对话从头重画一遍。前几轮感觉不到，十几轮之后越来越卡。

修复后，每吐出一段字只重画正在变化的那一条消息，对话再长也不会越用越卡。我们在 Windows 上用同一个 21 轮的长任务对比：

| | 0.22.1 | 0.22.2 |
|---|---|---|
| 界面最长一次连续卡住 | 93 秒 | 1.7 秒（只在第一轮启动时） |
| 超过 1 秒的卡顿次数 | 59 次 | 2 次 |
| 第 15 轮最长卡顿 | 33 秒 | 0.45 秒 |

## 已知问题（下一版修）

- 在画布上点生成时，偶尔会在结果写入的那一下短暂卡顿，装了会拦截程序启动的杀毒软件的电脑上更明显。
- 图片节点选「自动」比例生成后，节点框和图片比例对不上，图片四周会留白。
