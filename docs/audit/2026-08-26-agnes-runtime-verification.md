## 真实测试发现并修复

- V2.0 时长与帧率组合以前会静默 clamp 到 441 帧，例如 18 秒×60 fps 变成约 7.35 秒。现在请求前拒绝不可表示组合，合法 8n+1 帧保留；新增边界测试。
- Nomi 本地图片之前不能作为 AI SDK 图片字节读取。现在复用已有项目素材解析器，缺失图片或非图片 MIME 在发请求前失败；已有越界符号链接测试仍通过。
- 官方文档示例使用两关键帧，但没有写清最小数量；真实上游明确返回至少两图要求。关键帧槽 min=2，纯请求验证也拦截一图，不能只在 UI 修表象。最大数量仍不编造。
- 同步新主线后补齐旧 Image 2.1 像素尺寸到档位/比例的迁移：先从原宽高匹配目标档案的比例选项，再使用合法尺寸档位；显式比例不覆盖，旧模式和图片引用保留。
- 真实设置页发现 Image 2.1 详情显示两种生成方式，编辑页却落为空白默认模式。根因是内置档案未公布 max 被严格自定义契约校验整体拒绝。已移除这条错误中转，直接投影受信任内置档案；编辑自定义覆盖的保存校验仍要求用户明确本地上限，不把未知上游上限伪造为某个数字。已有全部档案草稿测试新增模式身份保留断言，防止空白回退冒充通过。
