## 五、仪器教训（已沉淀记忆）

- 探针只按文字模式过滤会瞎掉置顶模态：两次把「确认卡在等」误诊为「按钮死了」。**先查 topmost modal 再下结论**。
- **量几何要量对对象**：Mantine Modal 的 root 壳结构性恒 h=0（子层全 fixed 脱流），拿它量出「0 高」≠不可见；且**没截图亲眼看就下「不可见」结论=眼见链违规**（F16 误诊全案，防再犯护栏见 PR #168）。
- 截图必须缩到 ≤1400px 再 Read（多图会话对 >2000px 拒收）。
- `launchNomiApp` 只收 userDataDir 时会给 settings/projects 生成临时默认值并**覆盖 shell env**（详见 iso-walkthrough-key-seeding-traps 记忆）。
